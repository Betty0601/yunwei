# 热与功耗预算

## 1. 电池能量预算

| 项目 | 符号 | 值 | 单位 |
|------|------|-----|------|
| 电池额定电压 | V_bat | 22.2 | V |
| 电池额定容量 | Q_bat | 2.5 | Ah |
| **总能量** | **E_bat** | **22.2 × 2.5 = 55.5** | **Wh** |
| 续航目标 | t_run | 3 | h |

### 1.1 理想平均功率预算（忽略所有损耗）

$$ P_{\text{ideal,avg}} = \frac{E_{\text{bat}}}{t_{\text{run}}} = \frac{55.5}{3} = 18.5 \text{ W} $$

⚠️ **重要警告**：18.5 W 是**忽略所有损耗**的理想值，实际系统需要额外承担电机损耗、驱动损耗、传动损耗、控制板损耗等。

## 2. 功耗分解框架

### 2.1 功率流示意

```
┌─────────────────────────────────────────────────────────────┐
│ 电池 55.5 Wh / 3 hr                                         │
│                                                             │
│  P_battery ≈ 18.5 W (理想)                                  │
│  │                                                          │
│  ├──▶ 控制板/传感器 P_ctrl  ≈ 1-3 W                         │
│  │                                                          │
│  ├──▶ 驱动器损耗    P_drv   = PARAMETERIZED (MOSFET 导通+开关)│
│  │                                                          │
│  └──▶ 电机输入      P_motor,elec                             │
│       │                                                     │
│       ├──▶ 电机铜损  P_cu    = I²R, PARAMETERIZED            │
│       ├──▶ 电机铁损  P_fe    = PARAMETERIZED, 随 f 变化       │
│       └──▶ 机械输出  P_motor,out                             │
│            │                                                │
│            └──▶ 传动损耗 P_gear = P_mech × (1 - η)          │
│                 │                                           │
│                 └──▶ 执行机构机械功率 P_mech                 │
│                      ├── 惯性功率 P_inertia                  │
│                      ├── 摩擦功率 P_friction                 │
│                      └── 接触/组织功率 P_contact              │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 各项说明

| 损耗项 | 符号 | 估算范围 | 计算方式 | 备注 |
|--------|------|---------|----------|------|
| 控制板/传感器 | P_ctrl | **1 - 3 W** | 微控制器 + IMU + 指示灯 | 可在待机/工作间切换 |
| 驱动器 | P_drv | **1 - 5 W** | 取决于 MOSFET 导通电阻、开关频率、PWM 频率 | 参数化 |
| 电机铜损 | P_cu | **PARAMETERIZED** | P_cu = I²R（绕组电阻 × 电流²） | 铜损 ∝ I² |
| 电机铁损 | P_fe | **PARAMETERIZED** | P_fe ∝ f^α (α ≈ 1.3-1.5)，与频率强相关 | 高频档显著增加 |
| 传动损耗 | P_gear | **PARAMETERIZED** | P_gear = P_motor,out × (1 - η) | 取决于传动类型 |
| 摩擦/接触 | P_fric+contact | **PARAMETERIZED** | 取决于法向力、摩擦系数、接触阻尼 | 取决于治疗头与组织的耦合 |

### 2.3 总损耗关系

$$ P_{\text{battery}} = P_{\text{mech}} + P_{\text{gear}} + P_{\text{cu}} + P_{\text{fe}} + P_{\text{drv}} + P_{\text{ctrl}} $$

$$ P_{\text{battery}} = P_{\text{mech}} + P_{\text{motor,losses}} + P_{\text{gear}} + P_{\text{ctrl}} $$

其中：
$$ P_{\text{motor,losses}} = P_{\text{cu}} + P_{\text{fe}} $$

## 3. 热模型

### 3.1 热阻定义

$$ R_{\text{th,case}} = \frac{T_{\text{motor,case}} - T_{\text{amb}}}{P_{\text{total,loss}}} $$

其中：
- T_motor,case = 电机外壳温度 (°C)
- T_amb = 环境温度 (°C)，假设 25°C
- P_total,loss = P_cu + P_fe + P_gear + P_drv（控制板损耗通常较小，可计入或单独计算）
- R_th,case = 热阻 (°C/W)，取决于散热路径、外壳材质、空气对流条件

### 3.2 温升约束

假设电机允许外壳温度 ≤ 65°C（内部绕组 ≤ 120°C 典型 BLDC 等级 B 绝缘），环境温度 25°C：

$$ \Delta T_{\text{max}} = 65 - 25 = 40 \text{ °C} $$

$$ P_{\text{total,loss,max}} = \frac{\Delta T_{\text{max}}}{R_{\text{th,case}}} $$

**参数化示例**：

| R_th,case (°C/W) | P_total,loss,max (W) | 备注 |
|------------------|---------------------|------|
| 1.0 | 40 | 很好的散热（带铝壳+主动风冷） |
| 1.5 | 26.7 | 良好散热（铝壳，自然对流） |
| 2.0 | 20 | 中等散热（塑料壳或小铝壳） |
| 3.0 | 13.3 | 较差散热（紧凑，自然对流差） |

### 3.3 热与功率预算的耦合

**关键约束**：不仅需要 P_battery ≤ 18.5 W（理想能量预算），还需要 P_total,loss ≤ ΔT_max / R_th 满足热约束。

如果 18.5 W 电池预算可接受，且散热 R_th = 1.5 °C/W：
- 允许总损耗 ≤ 26.7 W（热约束）
- 但如果 P_battery 只能 ≤ 18.5 W，且 P_mech + P_ctrl ≈ 10-15 W，则损耗只剩 3-8 W
- **热约束可能比能量约束更松**（因为小体积设备热阻较大），但能量约束是硬边界

## 4. 18.5 W 预算是否足够？

### 4.1 回顾 dynamics_report 计算

| 工况 | m_eff | η | P_motor,out (W) | 估算 P_motor,elec (W) | 估算 P_battery_total (W) |
|------|-------|---|----------------|-----------------------|------------------------|
| f=15 Hz, 乐观 | 0.05 kg | 0.90 | 2.1 | ~2.5 | ~5.5 |
| f=30 Hz, 乐观 | 0.05 kg | 0.90 | 18.6 | ~22 | ~25 |
| f=30 Hz, 中等 | 0.10 kg | 0.90 | 37.1 | ~44 | ~47 |
| f=60 Hz, 乐观 | 0.05 kg | 0.90 | 149 | ~178 | ~181 |

### 4.2 分析

1. **15 Hz 档**：即使中等参数也能轻松在预算内运行 ✅
2. **30 Hz 档**：只有 m_eff ≤ 50 g、η ≥ 0.90 的**乐观情况**才可能接近预算边界（~25 W，略超 18.5 W）
3. **45 Hz 及以上**：**显著超出预算**（即使 m_eff = 50 g, η = 0.90, 仍达 ~250 W）
4. **60 Hz 档**：**不可能在 18.5 W 预算下运行**——差距一个数量级

### 4.3 核心矛盾

> **18.5 W 是"忽略所有损耗"的"理想输入功率"，但它甚至不够覆盖 30 Hz 下的机械输出功率。**

这意味着二选一：
- **方案 A**：重新定义电池 → 更大容量（更重、可能超出 1.6 kg 重量目标）
- **方案 B**：重新定义最高工作频率 → 下调至 30-40 Hz（放弃 60 Hz 档）
- **方案 C**：重新定义振幅 → 60 Hz 档自动减小行程（机构设计需自适应）

### 4.4 建议

1. 30 Hz / 20 mm 为**标准档位**，在此基础上优化 m_eff 和 η 使 P_battery ≤ 20-25 W（略超 18.5 W，考虑电池容量预留 20%）
2. 60 Hz 档作为**增强档位**，允许缩短续航（例如 15-20 min），或减小振幅（自动降行程至 5-10 mm）
3. 阶段 4 必须通过样机实测确定 P_mech、P_cu、P_fe、P_gear 的实际值，参数化模型暂不能用于定量化设计决策

## 5. 电池选型注意事项（简要）

| 参数 | 建议范围 | 备注 |
|------|---------|------|
| 持续放电倍率 | ≥ 10C（25A） | 机械功率峰值时电流会突增 |
| 峰值放电倍率 | ≥ 20C（50A） | 启动冲击、60 Hz 瞬态 |
| 重量 | ~200-280 g | 见 weight_budget |
| 保护电路 | 必须 | 过充、过放、过流、短路 |
| 平衡 | 必须 | 6S 电池电压高 |
