# 性能冲突分析

## 1. 设计空间

本项目的关键规格共同构成了一个**六维设计空间**：

| 维度 | 目标值 | 性质 |
|------|--------|------|
| 频率范围 | 15 - 60 Hz | **硬约束**（功能需求） |
| 行程 | 20 mm（峰峰值） | **硬约束** |
| 电池电压 | 22.2 V（6S LiPo） | **约束**（已选） |
| 续航 | 3 hr | **软约束**（可接受缩短） |
| 重量 | ≤ 1.6 kg | **软约束** |
| 噪声 | ≤ 45 dB(A) | **软约束**（需要确认测试条件） |

## 2. 冲突识别矩阵

| 维度冲突 | 描述 | 严重程度 | 解决方向 |
|----------|------|---------|---------|
| **高频 × 大行程** | f↑ → a_max ∝ f² 暴涨；S↑ → e↑ → 同样暴涨加速度 | 🔴 严重 | 60 Hz 档降振幅；或降 f_max |
| **高频 × 功耗** | P_mech ∝ f³A²（P = Fv = m·a·v ∝ f²·f·A³） | 🔴 严重 | 减小 m_eff；降 f_max |
| **高频 × 噪声** | f↑ → 冲击频率成分↑、轴承噪声↑、结构易共振 | 🔴 严重 | 动态平衡；精密机构；降 f_max |
| **大行程 × 机构体积** | e ∝ S/2，大行程需要更大偏心/更长连杆 | 🟡 中等 | 优化机构布置 |
| **续航 × 重量** | 更大电池 → 更重 | 🟡 中等 | 更高能量密度电池；减小 m_eff |
| **噪声 × 机构精度** | 低噪声需要精密机构 → 成本↑、可能更重 | 🟡 中等 | 动态平衡补偿粗精度 |
| **功耗 × 热** | P↑ → 热↑ → 需要更大散热 → 重量↑ | 🟡 中等 | 通过降低 P 同时解决 |
| **高频 × 轴承寿命** | 3600 r/min + 145 g 加速度 → L10 寿命急剧下降 | 🔴 严重 | 精密轴承；对置质量减载 |

## 3. 三种设计组合 Trade-off 分析

### 3.1 架构 A：基础单驱动偏心

**方案描述**：单个偏心轮 + 直接或通过连杆驱动治疗头，无动态平衡。

| 指标 | 评估 | 说明 |
|------|------|------|
| 复杂度 | ⭐ 低 | 零件少，装配简单 |
| m_eff | 中（~100 g） | 治疗头 + 连杆 + 偏心轮部分往复 |
| 功耗 | 🔴 高 | 全惯性力需要电机克服 |
| 振动 | 🔴 严重不平衡 | 一阶旋转惯性力未平衡，二阶往复惯性力未平衡 |
| 噪声 | 🔴 高 | 不平衡力 → 结构振动 → 辐射噪声 |
| 轴承寿命 | 🔴 短 | 不平衡力直接作用于轴承 |
| 成本 | 💰 低 | — |
| 60 Hz 可行性 | ❌ 难 | 功耗、噪声、轴承寿命均不达标 |

**结论**：架构 A 在 15-30 Hz 可能勉强工作，但 45-60 Hz 档**几乎不可能达标**。

### 3.2 架构 B：对置质量动态平衡

**方案描述**：在偏心轮对侧安装反向运动的平衡质量（或对置偏心轮），抵消一阶（和部分二阶）惯性力。

| 指标 | 评估 | 说明 |
|------|------|------|
| 复杂度 | ⭐⭐⭐ 中高 | 需设计平衡块、增加一个执行端或对称结构 |
| m_eff（往复） | 低（~30-50 g 治疗头端） | 平衡块分担了大部分惯性 |
| 功耗 | 🟢 显著降低 | 平衡块抵消惯性，电机只需做有用功 + 克服接触负载 |
| 振动 | 🟢 一阶力完全平衡（理想） | 若设计得当，一阶、二阶力均可以平衡 |
| 噪声 | 🟢 显著降低 | 不平衡力是主要噪声源，平衡后大幅改善 |
| 轴承寿命 | 🟢 显著延长 | 轴承载荷大幅降低 |
| 成本 | 💰💰 中 | 多一些零件和装配要求 |
| 60 Hz 可行性 | ✅ 可行 | 这是唯一有望在 60 Hz 档达标方案 |

**关键技术**：
- 一阶平衡：m₁ × r₁ × ω₁² + m₂ × r₂ × ω₂² = 0（矢量和）
- 二阶平衡：需要更复杂的对置连杆
- 实际上医疗设备通常做到一阶平衡即可，噪声和振动改善已经非常显著

**潜在问题**：
- 增加的平衡机构本身也有质量 → 对电机的"有用功率"之外还有"平衡功率"
- 空间布局更复杂
- 动态平衡不完全理想（制造误差、摩擦、弹性）

### 3.3 架构 C：曲柄连杆 / 凸轮对照

**方案描述**：经典曲柄连杆或盘形凸轮机构。

| 指标 | 评估 | 说明 |
|------|------|------|
| 复杂度 | ⭐⭐ 中 | 比偏心稍复杂 |
| 运动波形 | 非正弦，含谐波 | 见 kinematics_report 3.2 节 |
| m_eff | 中 | 与偏心类似 |
| 功耗 | 略高于偏心（峰值 a 更高） | λ = r/L 越大，峰值加速度越高 |
| 振动 | 与偏心类似（无平衡） | — |
| 噪声 | 略高（二次谐波 + 可能的冲击） | — |
| 轴承寿命 | 略短（轴承承受侧向力） | — |
| 60 Hz 可行性 | ❌ 难（比 A 更差） | — |

**凸轮机构的特殊问题**：
- 60 Hz 下的凸轮-从动件接触力和磨损
- 高副接触在高频下噪声大、寿命短
- 热膨胀导致间隙问题

**结论**：架构 C 不优于 A，不推荐作为主方案。但可以作为对照用于仿真验证。

## 4. 综合建议

### 4.1 主方案推荐：架构 B + 自适应振幅

| 项目 | 决策 | 理由 |
|------|------|------|
| 主架构 | **B（动态平衡）** | 唯一能覆盖全频率范围 |
| 振幅策略 | **高频降振幅** | 60 Hz 档自动从 20 mm 降到 8-10 mm，降低加速度 |
| 目标 m_eff | **≤ 50 g**（治疗头端） | 功耗控制 |
| 噪声测试 | **先冻结条件再验收** | 当前 45 dB(A) 无测试条件定义 |

### 4.2 决策矩阵总结

| 维度 | 硬约束 | 软约束 | 设计手段 |
|------|--------|--------|---------|
| f = 60 Hz | ✅ 必须覆盖 | — | 动态平衡 + 降振幅 |
| S = 20 mm | — | 目标（低档保持） | 高档降为 TBD |
| 续航 3 hr | — | 可接受缩短 | P_mech 优化 |
| 重量 ≤ 1.6 kg | ✅ | — | 见 weight_budget |
| 噪声 45 dB(A) | — | 分档 | 动态平衡 + 精密装配 |
