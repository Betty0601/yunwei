# 电机候选选型简报

## 1. 需求框架

| 需求项 | 指标 | 备注 |
|--------|------|------|
| 供电电压 | 22.2 V（6S LiPo） | 范围 18.0-25.2 V |
| 频率覆盖 | 15 - 60 Hz 机构往复 | 直接耦合 → 电机转速 900-3600 r/min |
| 振幅 | 20 mm 峰峰值 | 直接耦合时 e = 10 mm |
| 峰值机械功率 | **PARAMETERIZED** | 取决于 m_eff 和 f（见 dynamics_report） |
| 平均机械功率 | **PARAMETERIZED** | 可能 10-60 W 范围 |
| 转矩 | **PARAMETERIZED** | 0.2 - 0.8 N·m 范围（取决于 f 和负载） |

### 2.3 逐个深入

#### BLDC（无刷直流电机）— **强烈推荐**

| 属性 | 详情 |
|------|------|
| 驱动方式 | 6 步换相，方波或准正弦 |
| 典型极对数 | 7-14 极对 |
| 典型规格（我们需要的功率级） | 22.2V, 30-80W, 2000-4000 r/min，重量 100-200 g |
| PWM 频率 | 8-20 kHz（选 ≥ 20 kHz 可避开可闻噪声） |
| 控制算法 | 开环 V/f、闭环 6 步、高级 FOC（推荐 FOC 以降低转矩脉动） |
| 优点 | 功率密度高、效率高、寿命长、驱动芯片便宜、货源充足 |
| 缺点 | 方波驱动有转矩脉动（产生噪声）；用 FOC 可解决但驱动更复杂 |

**关键建议**：如果预算允许，选 **FOC 驱动的 BLDC 或表贴式 PMSM**，正弦波电流驱动大幅降低齿槽转矩和脉动噪声。

#### PMSM（永磁同步电机）— 可选

本质上 PMSM 是 BLDC 的正弦波/磁链定向控制版本。表贴式 PMSM（SPMSM）比内埋式（IPMSM）更适合我们：
- 气隙均匀 → 齿槽转矩小 → 噪声低
- FOC 控制效率最高
- 缺点：需要编码器或无感观测，驱动更复杂

#### VCM（音圈电机）— 线性直接驱动备选

**颠覆式方案**：直接做直线往复，不需要偏心/曲柄连杆机构！

| 属性 | 详情 |
|------|------|
| 原理 | 永久磁铁 + 载流线圈，洛伦兹力直接产生往复运动 |
| 行程 | 受限于线圈长度，20 mm 峰峰值可行 |
| 峰值力 | 取决于电流，轻松达到 10-30 N |
| 优点 | 无轴承、无偏心、无连杆 → **理论上最安静**；无机械传动损耗；控制简单（位置/速度/力闭环） |
| 缺点 | 推力随行程下降（边缘效应）；需要位置传感器；行程大时线圈体积增大；成本高 |
| 适合度 | 如果 60 Hz / 145 g 的加速度能克服 — **值得评估** |

⚠️ 但是：60 Hz 下 a_max = 1420 m/s² ≈ 145 g，且 VCM 的效率在**高频大加速度**下可能不如旋转电机 + 机构（因为感应电压和驱动电压限制）。需要详细仿真。

#### 步进电机 — 不推荐

- 齿槽效应严重 → 噪声大
- 效率低 → 发热大
- 体积/功率比不占优
- 调速困难

#### 有刷直流电机 — 不推荐

- 电刷磨损 → 寿命短
- 电刷火花 → EMI 问题
- 噪声比无刷高

## 3. 明确不做的事

> **本简报不推荐具体电机型号**，因为：
>
> 1. m_eff 和实际负载数据尚未通过样机验证（PARAMETERIZED）
> 2. 频率-振幅策略（特别是 60 Hz 档是否降振幅）尚未冻结
> 3. 驱动方案（方波 BLDC vs FOC PMSM vs VCM）仍需要仿真对比
> 4. 重量目标允许 150-250 g，但精确到哪一端需要 BOM 阶段确定
> 5. 市场供货渠道、价格、认证（特别是医疗相关）需要后续调研

**阶段 4 电机选型输入条件**（必须先确定）：

| 条件 | 需要确定的值 | 来源 |
|------|-------------|------|
| 方案 A 或 B 或 VCM | 旋转 + 机构 vs 直接 VCM | 架构决策 |
| m_eff 实际值 | 治疗头端等效质量 | 初步样机称重 |
| f = 60 Hz 是否保持 20 mm | 振幅策略 | 临床/产品决策 |
| 是否用减速/传动 | 直接耦合 vs 带传动 | 噪声/效率权衡 |
| FOC 预算 | 是否允许更高端驱动 | BOM 预算 |

## 4. 建议的下一步工作

1. **阶段 4 早期**：做 BLDC（带 FOC）vs SPMSM vs VCM 的对比仿真
2. **阶段 4 中期**：用简化机构样机测 m_eff、F_inertia、P_mech 的实际值
3. **阶段 4 末期**：参数冻结后，联系电机供应商要样件测试
4. **关注货源**：跨境电商（如 TMotor、Hobbywing）和国内微特电机厂

## 5. 结论

- **首选方案**：FOC 驱动的 BLDC 或 SPMSM 旋转电机 + 偏心/曲柄连杆 + 动态平衡
- **备选方案**：VCM 线性直接驱动（如果噪声约束真的非常严苛）
- **不推荐**：有刷直流、步进电机
- **选型时机**：**不是现在**，等阶段 4 参数冻结
