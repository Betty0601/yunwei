## 第一章 系统完整架构总览

### 1.1 系统分解树

NOTE6 的系统可以按能量流/运动流分解为以下层次：

```
NOTE6 完整系统
│
│  ┌─────────────────────────────────────────┐
│  │  能量输入层：电池组（6S LiPo 22.2V）       │
│  │  └→ 电能 → 电机控制板 PWM → 电机绕组        │
│  └─────────────────────────────────────────┘
│                    │ 电能
│                    ▼
│  ┌─────────────────────────────────────────┐
│  │  能量转换层：55mm 有感无刷电机               │
│  │  └→ 电能 → 旋转机械能（ω = 2100-3300 rpm）  │
│  └─────────────────────────────────────────┘
│                    │ 旋转机械能（T = 400+ mN·m）
│                    ▼
│  ┌─────────────────────────────────────────┐
│  │  运动变换层：偏心轮-连杆-活塞杆传动          │
│  │  └→ 旋转 → 直线往复（20mm 峰-峰）           │
│  │     机械利益 i = F_output / T_motor          │
│  └─────────────────────────────────────────┘
│                    │ 直线往复力（F_peak ≈ 255N堵转）
│                    ▼
│  ┌─────────────────────────────────────────┐
│  │  作用层：按摩头 → 人体肌肉/筋膜              │
│  │  └→ 机械冲击 → 软组织振动 → 放松效果         │
│  └─────────────────────────────────────────┘
```

### 1.2 完整自由体图（FBD）概要

在开始数学建模之前，先明确系统中每个部件的受力状态：

| 部件 | 自由度 | 主要受力 | 运动形式 |
|------|--------|---------|---------|
| 电机转子 | 1（绕轴旋转） | 电磁转矩 + 轴承摩擦 + 偏心轮反力矩 | 恒速旋转（理想）/ 脉动旋转（实际） |
| 偏心轮 | 1（绕电机轴旋转） | 电机转矩 + 连杆反力 + 自身离心力 | 旋转 + 不平衡力（需动平衡） |
| 连杆 | 平面运动 | 偏心轮铰接反力 + 第二轴承铰接反力 + 自身惯性力 | 摆动 + 平动合成（复杂平面运动） |
| 活塞杆 | 1（沿轴线往复） | 连杆推力 + 轴承反力（侧向） + 惯性力 + 皮肤反力 | 简谐往复（近似） |
| 第一轴承 | 固定外圈，旋转内圈 | 偏心轮-连杆的径向/轴向力 | 旋转 |
| 第二轴承 | 固定内圈，旋转外圈（或反之） | 连杆-活塞杆的径向力 | 摆动旋转 |
| 电机端轴承 | 固定外圈，旋转内圈 | 电机转子 + 偏心轮的径向/轴向力 | 旋转 |
| 电池组 | 固定 | 振动加速度（惯性力） | 随整机振动 |
| 外壳 | 固定（人手支撑） | 电机减震垫反力 + 轴承安装座反力 + 用户握持力 | 随整机振动（目标 < 0.5g） |

## 第二章 传动系统运动学精确模型

### 2.1 机构定义与坐标约定

NOTE6 的传动机构是**偏心轮-连杆-活塞（Eccentric-Link-Piston）机构**，本质上是曲柄滑块机构的变体——用偏心轮代替曲柄销（偏心轮的质心偏离旋转轴）。

#### 2.1.1 几何参数定义

```
            ┌───────────┐
            │   偏心轮    │  偏心距 e（旋转中心到连杆铰接点距离）
            │  ●───────● │
            │  电机轴    │  连杆铰接点 A
            └─────┬─────┘
                  │ 连杆 长度 L
                  │  (与活塞杆轴线夹角 β)
                  └─────┬─────┐
                        B ●    │
                       (铰接)  │ 活塞杆（沿 x 轴往复）
                               │
                              x(t) →
                          按摩头
```

| 参数 | 符号 | 估计值 | 待拆机 |
|------|------|--------|--------|
| **偏心距** | e | ≈ 10 mm | ✅ 核心测量 |
| **连杆长度** | L | ≈ 40-60 mm | ✅ 核心测量 |
| **连杆比** | λ = e/L | ≈ 0.17-0.25 | ✅ 由 e/L 计算 |
| **电机角速度** | ω | 2100-3300 rpm = 220-346 rad/s | 已知 |
| **曲柄转角** | θ | 0 - 2π rad | 变量 |

**关键发现**：当 λ ≤ 0.3 时，机构特性接近简谐运动（误差 < 5%），这是设计的理想区间。NOTE6 参数 λ 估计在 0.17-0.25 范围，属于理想区间。

### 2.2 位移方程（精确 + 近似）

#### 2.2.1 精确位移方程

活塞杆位置 x 从偏心轮旋转中心算起：

```
x(θ) = e·cos(θ) + √(L² - e²·sin²(θ))
```

推导过程（见附录 B）：偏心轮铰接点 A 的坐标为 (e·cosθ, e·sinθ)，连杆长度 L = AB，B 点在 x 轴上 → B_x = e·cosθ + √(L² - e²·sin²θ)。

#### 2.2.2 位移的傅里叶展开（物理意义）

将精确方程展开为级数形式，揭示运动的谐波成分：

```
x(θ) ≈ e·cosθ + L - (e²/2L)·(1 - cos2θ) + (e⁴/8L³)·cos4θ
     = [L - e²/(2L)] + e·cosθ + (e²/(2L))·cos2θ + ...
     
x_mean = L - e²/(2L)   （平均位置，相当于活塞行程的中点）
x_1 = e                 （一阶谐波幅值，决定峰-峰行程）
x_2 = e²/(2L)           （二阶谐波幅值，决定运动不对称性）
```

**峰-峰行程**（从 θ=0 到 θ=π 的总位移）：
```
S = x(0) - x(π) = [e + √(L² - 0)] - [-e + √(L² - 0)] = 2e

NOTE6：S = 20mm → e = 10mm ✓（完美确认！）
```

这证实了我们之前的推断：**NOTE6 的单机振幅 A = 偏心距 e = 10mm，峰-峰行程 S = 20mm**，精确到毫米。

#### 2.2.3 简化近似（当 λ 很小时）

当 λ = e/L ≤ 0.3 时，二阶项及以上可忽略：
```
x(θ) ≈ e·cosθ + L
活塞位移（从平衡位置算起）：x'(θ) ≈ e·cosθ
这就是简谐运动！与实际 NOTE6 运动误差 < 5%。
```

### 2.3 速度方程

对位移求导（精确）：
```
v(θ) = dx/dθ · dθ/dt = -ω·e·sinθ - ω·(e²·sinθ·cosθ)/√(L² - e²·sin²θ)
```

简化近似（λ 小时）：
```
v(θ) ≈ -ω·e·sinθ
v_max = ω·e（在 θ = 90° 或 270° 时）
```

### 2.4 加速度方程（含二阶谐波）

对速度求导（精确）：
```
a(θ) = dv/dθ · ω = -ω²·e·cosθ - ω²·e²·(cos²θ - sin²θ)/√(L² - e²·sin²θ) + ...
```

工程常用近似（保留到二阶，精度足够）：
```
a(θ) ≈ -ω²·e·(cosθ + λ·cos2θ)

a_max ≈ ω²·e·(1 + λ)    （在 θ=0°，上止点附近，最严酷工况）
a_min ≈ -ω²·e·(1 - λ)   （在 θ=180°，下止点附近）
```

**物理意义**：
- 一阶项 ω²·e·cosθ 是简谐加速度
- 二阶项 ω²·e·λ·cos2θ 是非线性修正（连杆有限长度导致）
- a_max > |a_min| → 加速度不对称，上止点附近更严酷 → 设计上以此为基准

### 2.5 连杆摆动与侧倾力

连杆角 β（连杆与活塞杆轴线的夹角）：
```
sinβ = (e·sinθ) / L

β_max = arcsin(e/L) = arcsin(λ)  ≈ λ（小角度近似）
NOTE6 估计：β_max ≈ 0.17-0.25 rad ≈ 10-14°
```

连杆产生的**侧倾力**（垂直于活塞杆轴线方向）：
```
F_side = F_axial · tanβ ≈ F_axial · λ

侧倾力由：
1. 活塞杆套（滑套）内孔提供 → 需要足够支撑长度
2. 第二轴承提供 → 需要足够的径向承载能力
3. 外壳安装座提供 → 需要足够的结构刚度
```

## 第三章 传动系统动力学模型

### 3.1 质量分布与等效质量

NOTE6 的往复质量分布：

| 部件 | 估计质量 | 运动形式 | 等效到活塞的质量 | 来源 |
|------|---------|---------|----------------|------|
| 活塞（活塞杆 + 按摩头接口） | m_p ≈ 50-80 g | 全往复运动 | m_p | 等质量 |
| 连杆（铝合金 CNC） | m_l ≈ 15-30 g | 摆动 + 平动合成 | m_l,eq ≈ m_l/2（回转部分等效到活塞） | 理论力学公式 |
| 偏心轮（CNC 金属） | m_e ≈ 30-50 g | 全旋转运动 | m_e,eq ≈ m_e（质心在偏心距处） | 旋转质量 |
| 连杆铰接压盖/轴承内圈 | m_b ≈ 5-10 g | 旋转 + 小摆 | m_b,eq ≈ m_b | — |
| **总等效往复质量** | | | **m_rec = m_p + m_l/2** | 决定惯性力 |
| **总等效旋转质量** | | | **m_rot = m_e + m_b + m_l/2** | 决定离心力 |

**典型数量级估计**（等拆机精确称重）：
- m_p ≈ 60g，m_l ≈ 20g，m_e ≈ 40g，m_b ≈ 8g
- m_rec ≈ 60 + 10 = **70 g**
- m_rot ≈ 40 + 8 + 10 = **58 g**

### 3.2 往复惯性力（一阶 + 二阶）

活塞 + 连杆的往复部分产生的惯性力：

```
F_rec(θ) = -m_rec · a(θ)
         ≈ m_rec · ω² · e · (cosθ + λ·cos2θ)
         
F_rec,1(θ) = m_rec · ω² · e · cosθ          （一阶，与 ω² 成正比）
F_rec,2(θ) = m_rec · ω² · e · λ · cos2θ      （二阶，2×频率，ω²·λ）
```

NOTE6 5 档峰值（使用 m_rec = 70g, λ = 0.2）：

| 档位 | ω² (rad²/s²) | F_rec,1_max (N) | F_rec,2_max (N) | 合计 F_rec_max (N) |
|------|-------------|----------------|----------------|-------------------|
| 1 | 48340 | 34 | 6.8 | **40.8** |
| 2 | 63150 | 44 | 8.9 | **52.9** |
| 3 | 79820 | 56 | 11.2 | **67.2** |
| 4 | 98730 | 69 | 13.8 | **82.8** |
| 5 | 119440 | 84 | 16.7 | **100.7** |

**关键发现**：5 档峰值往复惯性力 **≈ 101N**，方向沿活塞杆轴线，交变频率与振动频率相同。这部分力**不传递到人体**（内部力），但会在壳体上产生**反作用力矩**，是整机振动的主要来源之一。

### 3.3 旋转惯性力（偏心轮 + 连杆回转部分）

绕电机轴旋转的偏心质量产生的离心力：

```
F_rot(θ) = m_rot · ω² · e_radial · 常数方向（径向）

其中 e_radial 是旋转质心偏离电机轴的距离（偏心距 e 加上连杆回转部分的等效偏心）
```

**旋转惯性力的特点**：
- 大小恒定（m_rot · ω² · e_rot）
- 方向沿径向（随 θ 旋转）
- 频率 = 电机旋转频率（与往复力相同频率，但方向不同）
- **这是必须动平衡的力**（不能抵消，只能通过平衡配重削减）

### 3.4 轴承载荷计算（第一轴承 + 第二轴承 + 电机轴承）

#### 3.4.1 第二轴承（活塞杆铰接点）— 承受交变力最大

第二轴承是连杆-活塞杆铰接点的轴承，受力条件最恶劣：

**径向载荷**（由连杆推力的侧向分量 + 惯性力引起）：
```
F_r2(θ) = F_axial · sinβ(θ) + m_l·(加速度分量)
       ≈ F_axial · λ · sinθ

在堵转时（按摩头抵住致密肌肉），F_axial 最大 = 255N
此时 F_r2_max ≈ 255 · 0.2 = 51 N
```

**轴承选取（估算）**：

## 第四章 偏心轮动态平衡设计

### 4.1 为什么必须动平衡？

偏心轮的质心**不**在电机旋转轴上。如果不做平衡配重：

```
离心力 F = m_rot · ω² · e_rot

5档（ω = 346 rad/s）：
e_rot ≈ 10mm（偏心距）
m_rot ≈ 58g
F = 0.058 × 346² × 0.01 ≈ 69 N！

69N 的交变力 → 直接传递到电机轴承 → 传递到外壳 → 用户感受到"震手"
→ 产生振动（声辐射）→ 噪声
→ 轴承寿命降低（交变载荷加速疲劳）
```

### 4.2 偏心轮质心偏移量计算

NOTE6 偏心轮的简化形状（假设圆盘 + 偏心臂）：

```
偏心轮简化模型：
┌───────┐      ┌───偏心臂───┐
│  圆盘   │──────│  ●          │  ← 电机轴孔（旋转中心）
│  m_disk │      │  m_arm    │     偏心距 e = 10mm
└───────┘      └───────────┘

质心位置 e_cm：
e_cm = (m_disk × 0 + m_arm × e) / (m_disk + m_arm)

假设 m_disk = 20g，m_arm = 20g，e = 10mm：
e_cm = (20×0 + 20×10) / 40 = 5 mm

总偏心质量距 = m_total × e_cm = 40g × 5mm = 200 g·mm
这就是需要被平衡掉的不平衡量！
```

### 4.3 平衡配重设计

**完全平衡方案**：在偏心轮的**对称侧**（180° 方向）添加/保留一个平衡质量 m_balance，使其满足：

```
m_original · e_cm = m_balance · e_balance

m_original · e_cm  = 原始不平衡量（200 g·mm）
e_balance          = 平衡配重质心到旋转轴的距离（通常 = e，对称位置）
m_balance          = 需要添加的平衡质量

NOTE6 估算：200 g·mm = m_balance × 10mm → m_balance = 20g
```

**实际做法**：
- 偏心轮在 CNC 加工时**预留平衡肉**（比目标质量重 5-10%）
- 粗加工后在**动平衡机上检测不平衡量和相位**
- 在对称侧**铣削去除多余材料**（CNC 精铣，铣出弧形槽或减重孔）
- 动平衡等级目标：**ISO 1940 G6.3 或 G2.5**（对应残余不平衡量 ≤ 2 g·mm）

### 4.4 倍益康动平衡技术推断

倍益康 D2 Max 官网明确说"**采用目前业内领先的动平衡技术**"。推断 NOTE6/K6/M2 系列共享这套技术：

| 手段 | 推断 | 依据 |
|------|------|------|
| CNC 精加工偏心轮 | ✅ 官网明示"CNC 精加工偏心轮" | 初始偏心距控制精度高（±0.01mm） |
| 动平衡机检测 | ✅ 行业标准做法，倍益康作为规模企业必然有 | 70+ 国家出口产品需要严格质量控制 |
| 铣削去重 | ✅ 偏心轮 CNC 加工流程中可能包含去重步骤 | 偏心轮通常会看到减重孔 |
| 连杆动平衡 | ❓ 连杆是摆动件（不是纯旋转），通常不做动平衡 | 连杆的不平衡力是二阶效应，已被活塞杆和轴承吸收 |
| 整机二次平衡 | ❌ 不可能（多自由度系统，无法单一平面平衡） | 主要平衡偏心轮本身 |

## 第五章 振动与噪声完整物理模型

### 5.1 振动激励源分解

NOTE6 的振动激励可以按频率分解：

| 激励源 | 频率 | 幅值 | 传递路径 |
|--------|------|------|---------|
| 偏心轮离心力（未平衡残余） | f₀ = 35-55 Hz | 未平衡量 × ω² × e | 电机轴承 → 外壳 → 人体/空气 |
| 连杆一阶往复惯性力 | f₀（同频） | m_rec × ω² × e | 轴承 → 壳体 → 人体 |
| 连杆二阶往复惯性力 | 2×f₀（70-110 Hz） | m_rec × ω² × e × λ | 同上 |
| 连杆二阶谐波（cos2θ） | 2×f₀ | 较小 | 同上 |
| 电机电磁转矩脉动 | f_motor = 电机极对数 × f₀ | 取决于电机设计 | 电机定子 → 外壳 |

| 寿命指数 p（球轴承） | 3 |
| 等效动载荷 P | 见下文 |

**等效动载荷 P 计算**：
- 径向载荷主分量 F_r ≈ 51 N（见 3.4.1 节）
- 轴向载荷 F_a ≈ 较小（估算 < 20 N）
- 对于深沟球轴承 F_a/F_r < 0.35 → X=1, Y=0
- P = X·F_r + Y·F_a = 1 × 51 = 51 N

**L10 寿命**（5档 3300rpm 连续运行）：
```
L10 = (C/P)³ = (5700/51)³ ≈ 22000 百万转

L10h = (10⁶ / (60×3300)) × 22000 = 5.05 × 22000 ≈ 111,000 小时
```

⚠️ 这是理想值！实际修正系数：
- 润滑系数 a_slime ≈ 0.8（有油槽润滑，良好）
- 污染系数 a_clean ≈ 0.7（内部环境，良好）
- 温度系数 a_temp ≈ 0.9（< 100℃，不影响）
- 修正寿命 L10_modified = 111000 × 0.8 × 0.7 × 0.9 ≈ **56,000 小时**

这比筋膜枪 3000-5000 小时的典型寿命长得多。这就是倍益康用**大动载轴承 + 好润滑**的原因——轴承寿命不是瓶颈。

#### 7.1.2 第一轴承

假设与第二轴承相同规格，载荷更大（P ≈ 100N）：
```
L10 = (5700/100)³ = 1850 百万转
L10h_modified ≈ 1850 × 5.05 × 0.5 ≈ **4700 小时**
```

这接近筋膜枪典型寿命上限。第一轴承是**磨损最严重的轴承**。

### 7.2 偏心轮/连杆疲劳寿命

#### 7.2.1 偏心轮

偏心轮承受：
- 旋转弯曲应力（偏心质量产生的离心力）
- 传递转矩的剪应力
- 安装面的接触应力（与电机轴、连杆）

**疲劳风险点**：
1. 连杆铰接孔周围（应力集中）
2. 偏心臂与圆盘的过渡圆角处
3. 与电机轴配合的键槽/紧固螺钉孔

CNC 精加工偏心轮（45# 钢或铝合金）：
- 如果用 40Cr 调质处理（HB 220-250），疲劳极限 ≈ 400 MPa
- 估算最大应力（保守）≈ 100-200 MPa
- 疲劳寿命 ≈ 10⁷-10⁸ 次循环 → **相当于 5 档连续运行 60-120 小时**（估算）
- ✅ 偏心轮本身疲劳寿命不是瓶颈（除非有加工缺陷）

#### 7.2.2 连杆

连杆是纯摆动件，两端铰接点附近应力最大。如果用 6061-T6 铝合金（倍益康官网说"铝合金传动臂"）：
- 6061-T6 疲劳极限 ≈ 70-100 MPa（旋转弯曲）
- 估算连杆最大应力 ≈ 30-50 MPa
- 疲劳寿命远高于偏心轮

### 7.3 活塞杆镀层磨损寿命

活塞杆往复运动时镀层与滑套摩擦，镀层逐渐磨损：

```
磨损量 W = K · P · L · t
  K = 磨损系数（硬铬镀 vs 钢 = 10⁻⁷ - 10⁻⁶）
  P = 正压力（≈ 50 N）
  L = 滑动距离（20mm/次 = 0.02m/次）
  t = 运行次数

每年运行次数（估计每天用 15 分钟 × 3 档）：
  30 次/分 × 15 分 × 365 天 ≈ 164,000 次

硬铬镀厚度 ≈ 10-20 μm（0.01-0.02 mm）
K = 5 × 10⁻⁷

年磨损量 ΔW = 5×10⁻⁷ × 50 × 0.02 × 164000 ≈ 0.082 mm

⚠️ 年磨损量 0.082mm，而镀层厚度通常只有 0.01-0.02mm！
这说明镀层磨损速度**远快于我们的计算**，或者：
1. 倍益康用了更耐磨的镀层（DLC？陶瓷镀层？）
2. 实际使用中不是每次都满负载
3. 油槽润滑大幅降低了 K 值
4. 硬铬镀实际厚度更大（0.05mm 量级）

这是拆机必须确认的关键参数：**镀层类型 + 镀层厚度**。

### 7.4 电机寿命

电机寿命的主要限制因素：

| 因素 | 寿命（小时） | 说明 |
|------|------------|------|
| **轴承** | 50,000+ | 见 7.1 |
| **绕组绝缘** | 20,000+ | F/H 级绝缘，85℃ 工作温度远低于 155/180℃ 限值 |
| **永磁体退磁** | 10,000+ | N42SH 耐 150℃，70℃ 安全 |
| **霍尔传感器** | 50,000+ | 固态器件，无机械磨损 |
| **有感 vs 无感** | 有感寿命更长 | 无感电机频繁堵转会导致过流损伤 |

**电机整体寿命估计 ≥ 10,000 小时**。这意味着每天使用 1 小时，大约可以用 **27 年**。电机远不是寿命瓶颈。

### 7.5 电池循环寿命

天津力神 18650 3C 动力型电芯：
- 100% 深度放电循环寿命 **> 500 次**（保持 80% 容量）
- NOTE6 每天用电池 1/5 → 循环 ≈ 2500 天 ≈ **6.8 年**（80% 容量）
- 电池寿命不是整机寿命瓶颈，但电池是整机重量瓶颈（占 1.2kg 的 30-40%）

## 第八章 公差链与装配干涉

### 8.1 关键公差链 1：偏心距 → 振幅

```
加工偏心距误差 Δe → 振幅误差 ΔA = Δe（直接传递，1:1）

目标：A = 10 ± 0.1 mm → e = 10 ± 0.1 mm
公差来源：偏心轮 CNC 加工精度 ±0.01 mm → 可满足 ✓

如果 e = 10.05 mm：
  A = 10.05 mm → 振幅误差 +0.5% → 可接受
如果 e = 9.95 mm：
  A = 9.95 mm → 振幅误差 -0.5% → 可接受
```

### 8.2 关键公差链 2：连杆长度 → 侧偏量

```
连杆长度误差 ΔL → 侧偏量 Δβ ≈ ΔL·cosβ/L

目标：侧偏 ≤ 0.05mm（滑套内孔与活塞杆的配合间隙）
连杆长度公差 ±0.05mm → Δβ ≈ 0.05·cos11.5°/50 ≈ 0.001 rad ≈ 0.06mm
→ 刚好触及间隙上限 → 需要更严 ±0.02mm 公差
```

### 8.3 关键公差链 3：轴承配合 → 噪声

```
轴承外圈与壳体配合：H7/js6（过渡配合，JS7/H6）
轴承内圈与轴配合：H7/m6（过盈配合）

间隙过大 → 轴承外圈松动 → 撞击声 → 高频噪声
间隙过小 → 过盈太大 → 轴承预紧 → 发热增大 → 磨损加速

公差链计算（轴承安装座 → 轴承 → 壳体孔）：
  壳体孔：φ22 H7 (+0.021/0)
  轴承外圈：φ22 js6 (±0.0065)
  配合间隙：-0.0065 ~ +0.0275 mm
  最大间隙 0.0275mm → 可接受（轴承有游隙余量）
```

### 8.4 装配干涉检查点

以下位置可能发生设计干涉，在 Fusion 360 建模时必须做干涉检查：

| 检查点 | 间隙要求 | 干涉后果 |
|--------|---------|---------|
| 偏心轮旋转时与壳体内壁 | ≥ 0.5 mm | 偏心轮蹭壳体 → 噪声 + 摩擦 |
| 连杆摆动时与壳体 | ≥ 1.0 mm | 连杆撞壳体 → 噪声 + 断裂风险 |
| 连杆摆动时与活塞杆套 | ≥ 0.3 mm | 连杆撞滑套底部 |
| 活塞杆往复时与按摩头接口 | ≥ 1.0 mm（行程余量） | 按摩头脱落或螺纹疲劳 |
| 电机与电池组 | ≥ 2.0 mm（散热间隙） | 电机热辐射导致电池温度升高 |
| 电机与上壳体内壁 | ≥ 1.0 mm（减震垫位置） | 减震垫被过度压缩 → 振动放大 |

## 附录 B 运动学公式推导完整过程

### B.1 位移精确方程推导

偏心轮铰接点 A 在固定坐标系中的坐标：
```
A_x = e·cos(θ)
A_y = e·sin(θ)
```

连杆两端铰接点 A 和 B 的距离为 L：
```
|AB|² = (B_x - A_x)² + (B_y - A_y)² = L²
```

B 点在活塞杆轴线上（B_y = 0）：
```
(B_x - e·cosθ)² + (0 - e·sinθ)² = L²
(B_x - e·cosθ)² + e²·sin²θ = L²
(B_x - e·cosθ)² = L² - e²·sin²θ
B_x - e·cosθ = ±√(L² - e²·sin²θ)
```

因为活塞只能向右运动（取正号）：
```
x(θ) = B_x = e·cosθ + √(L² - e²·sin²θ)
```

### B.2 傅里叶展开

把 √(L² - e²·sin²θ) 展开为二项式级数：
```
√(1 - (e/L)²·sin²θ) = Σ (n=0 to ∞) C(1/2, n)·(-1)^n·(e/L)^(2n)·sin^(2n)θ

其中 C(1/2, n) = (-1)^(n+1)·(2n-2)! / [2^(2n-1)·(n-1)!·n!] （广义二项式系数）
```

取前 3 项（精度足够）：
```
√(L² - e²·sin²θ) = L·[1 - (λ²/2)·sin²θ - (λ⁴/8)·sin⁴θ + ...]
```

用三角函数恒等式 sin²θ = (1-cos2θ)/2，sin⁴θ = (3-4cos2θ+cos4θ)/8 转换：
```
x(θ) ≈ e·cosθ + L - (L·λ²/4)·(1 - cos2θ) - (L·λ⁴/64)·(3 - 4cos2θ + cos4θ)
     = [L - L·λ²/4 - 3L·λ⁴/64] + e·cosθ + [L·λ²/4 + L·λ⁴/16]·cos2θ - L·λ⁴/64·cos4θ
```

忽略高阶小项（λ⁴ 及更小，当 λ ≤ 0.25 时，λ⁴ ≤ 0.0039 可忽略）：
```
x(θ) ≈ [L - e²/(2L)] + e·cosθ + (e²/(2L))·cos2θ
     = x_mean + x₁·cosθ + x₂·cos2θ

x_mean = L - e²/(2L)  ← 平均位置（活塞行程中点）
x₁ = e                ← 一阶谐波，决定行程 S = 2e
x₂ = e²/(2L)          ← 二阶谐波，决定运动不对称
```

### B.3 速度和加速度（精确公式）

```
v(θ) = dx/dθ · dθ/dt = -ω·e·sinθ + d/dθ[√(L² - e²·sin²θ)]·ω
     = -ω·e·sinθ + ω·(-e²·sinθ·cosθ)/√(L² - e²·sin²θ)
     = -ω·e·sinθ·[1 + e·cosθ/√(L² - e²·sin²θ)]

精确加速度 a(θ) = dv/dθ · ω（太复杂，工程用近似）：
a(θ) ≈ -ω²·e·(cosθ + λ·cos2θ)
```
