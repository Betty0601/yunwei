## 第一章 品牌背景与行业地位

### 1.1 公司概况

倍益康，全称**四川千里倍益康医疗科技股份有限公司**，是一家以康复理疗设备为核心业务的国家级高新技术企业、国家知识产权优势企业。公司成立于 2006 年，总部位于成都，在成都、深圳、东莞、香港设有 4 大研发制造和销售中心。2022 年 12 月 1 日在北京证券交易所上市，被誉为"A 股筋膜枪第一股"。

### 1.2 业务架构

倍益康的业务可划分为两大板块：

| 板块 | 内容 | 代表产品 |
|------|------|---------|
| **专业医疗（康复科技）** | 医院/康复中心/专业机构用设备 | DMS 深层肌肉刺激仪、制氧机、冲击波治疗仪、冷热敷加压设备、经皮脊髓电刺激仪 |
| **健康消费（筋膜枪等）** | 大众运动恢复和居家放松 | 筋膜枪全系列、便携式制氧机、微型睡眠辅助设备 |

2025 年公司营业收入 2.73 亿元，其中康复科技产品占 85.31%，康复医疗产品占 14.69%。

### 1.3 筋膜枪业务的起源与演进

倍益康的筋膜枪业务并非从零开始，而是**医疗技术民用化**的典型路径：

1. **2015 年**：推出医疗级 **DMS 深层肌肉刺激仪**（Deep Muscle Stimulator），通过高频垂直振动作用于肌肉组织，用于降低肌肉紧张性、解除肌肉痉挛、缓解肌肉疲劳。该产品服务于全国数千家医疗机构与康复中心，奠定了力疗领域的技术根基。
2. **2018 年**：洞察到同属垂直振动力疗类但适用于消费市场的"筋膜枪"机遇，凭借 DMS 技术积淀迅速推出首款拥有自主知识产权的消费级筋膜枪。
3. **2019 年**：创新性推出全球首款采用 **2 节锂电池 + Type-C 接口**的便携款筋膜枪 M2，引领行业向轻量化、便携化变革，一经推出即受美国、日本、俄罗斯等市场高度认可。2019-2022 年营业收入从 4000 万增长到 3.9 亿元，筋膜枪产品是绝对主力。
4. **2023 年**：推出全球首款**可落地量产的可变振幅筋膜枪 Ti Pro Max**，彻底告别传统固定振幅模式。值得注意的是，美国公司早在 2021 年就申请了可变振幅专利但无法商品化——从专利技术到商品需要跨越可实现性、可靠性、经济性三大鸿沟，倍益康率先完成跨越。
5. **2025-2026 年**：推出 D 系列可变振幅旗舰产品线（D2 Max / D3 Max / D6 Max），进一步巩固可变振幅技术领先优势。

### 2.2 各系列设计哲学

**专业款系列** 直接继承 DMS 医疗设备技术路径。追求最大振幅和最大推力，使用高压大容量电池（22.2V/2500mAh，6 节 18650 串联），整机重量通常 1.2-1.6kg，牺牲便携性换取绝对性能。核心架构是 **CNC 精加工偏心轮 + 金属活塞杆 + 进口轴承**。

**便携款系列** 以 M2 为代表，是倍益康最成功的产品之一。创新性地从 6 节电池缩减到 2 节（7.3V），引入 Type-C 统一充电口，重量降至 680g。在保持 8mm 振幅和 15kg 推力的同时大幅提升易用性，引领了整个筋膜枪行业向轻量化变革。M2 全球销量超百万台。

**可变振幅旗舰 D 系列** 是倍益康技术护城河的集中体现。官网明确披露其可变振幅技术源自 **航天探测器着陆腿刚度调节原理**（月球探测器着陆时根据载荷变化动态调节着陆腿长度/刚度）。通过"重构传统传动结构"实现连续可调振幅，而非简单的偏心距多档切换。D2/D3/D6 Max 的振幅范围科学分层：6-12mm（日常覆盖）、7-15mm（进阶运动）、8-16mm（专业深度），形成完整的性能梯度。

### 3.6 参数说明与注意事项

1. **堵转推力（Stall Force）**：指按摩头在物理受阻完全停止转动时电机能输出的最大力。这是衡量筋膜枪动力的**核心指标**，直接决定了能否在肌肉紧张、脂肪层较厚时仍能保持有效振幅。注意：市面上存在"推力虚标"现象（某些品牌标称 30kg 实际只 15kg），倍益康参数通过沙利文、SGS 等第三方验证，可信度高。
2. **单机振幅 vs 峰-峰行程**：单机振幅（A）是按摩头从中心到一端的距离；峰-峰行程（S=2A）是按摩头两端之间的总位移。两个概念经常被混用，本文统一标注。
3. **频率换算**：rpm（每分钟转速）÷ 60 = Hz（每秒振动次数）。Note6/PRO6 的 2100-3300 rpm = 35-55 Hz，这是一个关键的有效治疗频率窗口（详见第五章）。
4. **信息置信度**：A = 官网/手册明确数据；B = 展会/新闻稿；C = 推测/估算。

## 第四章 技术维度深度剖析

### 4.1 电机技术

电机是筋膜枪的"心脏"，直接决定推力、寿命、噪音和效率。倍益康全系产品统一采用**有感无刷电机**（Sensored Brushless Motor），区别于无感无刷和有刷电机。

#### 4.1.1 有感 vs 无感无刷

| 特性 | 有感无刷 | 无感无刷 | 有刷电机 |
|------|---------|---------|---------|
| **位置传感器** | ✅ 有（霍尔传感器） | ❌ 无（反电动势估算） | 有（碳刷） |
| **低速力矩** | 大（起步/堵转时优势明显） | 小（需在最低转速以上才能稳定） | 大 |
| **力矩控制** | 精准实时反馈 | 滞后（依赖反电动势估算） | 粗糙 |
| **寿命** | 极长（轴承磨损为主） | 长 | 中等（碳刷磨损） |
| **效率** | 高（90%+） | 中高 | 低（70% 左右） |
| **成本** | 较高 | 较低 | 最低 |
| **倍益康采用** | ✅ 全系 | ❌ | ❌ |

倍益康选择有感无刷的核心原因：**筋膜枪经常在"堵转"状态下工作**（按压到致密肌肉或骨骼附近时），有感电机能实时感知负载并调整输出，不会因过载失步或烧毁。NOTE6/K6 官网明写的"实时监控击打阻力，毫秒级反馈调整，动态平衡频率"就是有感电机 + 智能控制的组合能力。

#### 4.1.3 动态平衡技术

D2 Max 官网和 M2 Pro Max 新闻稿多次提到"业内领先的动平衡技术"。这是筋膜枪降噪的核心手段之一：

> 偏心轮系统天然存在旋转不平衡（因为质心偏离旋转中心）。不平衡量在高速旋转时产生交变力和力矩，直接传递到外壳 → 用户感受到的"震手"和噪音。

动平衡技术的做法是在偏心轮的配重端通过 CNC 精密去除或添加少量材料，使偏心轮组件的质心尽量靠近旋转轴。M2 Pro Max 明确写了"**动平衡技术既静音又减少谐振，提升握持舒适度**"。NOTE6/PRO6 的 ≤45dB 噪音水平也印证了这套技术的有效性。

#### 4.2.3 偏心距与振幅的关系

这是我们建模必须精确确定的参数：

```
单机振幅 A = 偏心距 e
峰-峰行程 S = 2A = 2e

PRO6/NOTE6:  A = 10mm  →  e = 10mm（注意：是从动轴中心到连杆连接孔中心的距离）
           等一下 — M2 的振幅是 8mm，官网没写偏心距，但结构应该相同
```

**修正**：实际传动中偏心距到振幅的关系不是简单 1:1。偏心轮通过连杆（通常带角度）驱动活塞杆，实际需要考虑连杆角度对行程的放大/缩小效应。简化公式：

```
A = e × cos(α)    其中 α 是连杆与活塞杆轴线的夹角
```

如果 α 很小（连杆接近直线连接），cos(α) ≈ 1，则 A ≈ e。M2 写的是 8mm 振幅，如果连杆角度小，偏心距就是 8mm 左右。NOTE6/PRO6 的 10mm 振幅，偏心距应该也在 10mm 左右（或略大，有连杆角度补偿）。

倍益康没有披露可变振幅的具体机械结构，但从官网信息可以做有根据的推断：

> 官网 D2 Max 新闻稿："**通过重构传统传动结构，实现 6-12mm 共 7 个振幅可调**"
> 官网 X Max 新闻稿："**Variable Depth 可变按摩深度科技源自航天探测器着陆腿刚度调节技术**"

航天探测器着陆腿刚度调节的原理是：载荷变化时，通过改变并联机构的"有效力臂长度"来改变刚度和行程。倍益康把这个思路移植到传动机构：

**推断方案**（可能不是唯一方案）：
```
电机轴 → 偏心轮 → 可移动连杆支点 → 活塞杆

         ┌─────────┐
         │ 偏心轮   │
         └────┬────┘
              │ 连杆
              │  ┌─── 可调节支点位置（电机驱动的微型调节机构）
              │  │   ↓ 支点远离输出端 → 振幅增大
              │  │   ↓ 支点靠近输出端 → 振幅减小
         ┌────┴──┴────┐
         │   活塞杆     │
         └────────────┘
```

这比"切换不同偏心距的偏心轮"更优雅——偏心距固定，通过改变连杆传递比来调节输出行程。也比传统方案更紧凑。这就是为什么倍益康说"重构传统传动结构"。

### 4.5 噪声控制

#### 4.5.1 噪声来源（按对总噪声的贡献排序）

| 噪声源 | 占比（估计） | 控制手段 | 倍益康做法 |
|--------|------------|---------|-----------|
| **偏心轮不平衡振动** | 35-45% | 动平衡配重 | 官网明示"业内领先的动平衡技术" |
| **轴承摩擦** | 20-30% | 高精度轴承 + 合理预紧 | NOTE6 明示"日本进口静音轴承" |
| **电机电磁噪声** | 15-25% | 槽满率 + 绕组设计 | D2 Max 槽满率 82%（降低磁阻脉动） |
| **传动副间隙冲击** | 10-15% | CNC 精密加工 + 合理间隙 | M2 明示"CNC 精加工滑套" |
| **风噪（冷却）** | 5-10% | 散热孔设计 | 蜂窝/顶部散热孔，减少涡流 |

#### 4.5.2 NOTE6 的 ≤45dB 为什么是行业标杆

45 dB(A) 大约相当于**安静的图书馆**或**正常谈话距离 1 米外的低语**。在 3300 rpm（55 Hz 高频模式）下还能保持这个水平，说明倍益康对上述 5 种噪声源都做了有效控制：

- **结构层面**：CNC 精加工偏心轮 + 日本进口静音轴承 + CNC 滑套 = 机械噪声极低

### 8.2 "双轴传动"的真实含义

此前对 Dr. Fuji 宣传的"双轴传动"有多种猜测（齿轮箱、谐波传动等），现在根据 NOTE6 官网描述可以确定：

> **双轴传动 = 电机驱动轴 + 从动输出轴**

```
┌────────────┐     ┌────────────┐     ┌────────────┐
│ 电机驱动轴  │────→│ 偏心轮 + 连杆 │────→│ 从动输出轴  │────→ 活塞杆 ──→ 按摩头
│            │     └────────────┘     │            │
└────────────┘                        └────────────┘
  动力来源                              支撑轴承（日本进口）
                                       这就是第 2 个"轴"！
```

为什么需要双轴？
- **电机轴**负责旋转驱动
- **从动轴**通过轴承支撑，减少摩擦和侧向力，保证活塞杆直线运动精度
- 两个轴配合 → "双轴传动"。这是一个合理的架构选择，不是什么黑科技或特殊机构

| **永磁材料** | 高标号钕铁硼（N42SH 或更高） | D2 Max 明示"高标号钕铁硼"，同系列 |
| **额定电压** | 22.2V（6S 串联） | 电池规格直接对应 |
| **额定电流（估算）** | 25W / 22.2V ≈ 1.13A | P = U × I |
| **堵转转矩（估算）** | ≥ 400 mN·m | M2 45mm 电机 = 350 mN·m；NOTE6/PRO6 55mm + 更大推力 → 至少 400 |
| **堵转电流（估算）** | ~5-7A | 有感无刷电机堵转电流通常是额定电流的 5-6 倍 |
| **槽满率（估算）** | 75-80% | D2 Max = 82%（行业领先）；NOTE6/PRO6 略低但仍属优秀 |
| **KV 值（估算）** | ~100-120 rpm/V | 22.2V × 110 rpm/V ≈ 2442 rpm ≈ 40.7 Hz（正好是 2 档！） |

**KV 值反推验证**：如果 KV ≈ 110 rpm/V，在 22.2V 下空载转速 ≈ 2442 rpm，接近 2 档（2400 rpm）。随着档位升高，电压或电机控制策略变化（PWM 占空比增大），转速继续上升。这个估算的合理性很高。

### 8.5 对性能规格的修正建议

基于本次研究的发现，建议对项目早期制定的性能目标做以下修正：

| 原目标 | 建议修正为 | 修正原因 |
|--------|----------|---------|
| 15-60 Hz 连续调频 | **35/40/45/50/55 Hz 五档离散** | NOTE6/PRO6 实际就是五档离散，且正好覆盖学术研究确认的治疗窗口。连续调频不是必须，离散档位更符合医疗/康复设备的规范化使用习惯 |
| 20mm 振幅 | **方案 A：10mm 固定（复刻 PRO6）** **方案 B：8-16mm 可变（超越 D 系列）** | 20mm 在消费级物理上过于极端（a_max 在 55Hz 时 ≈ 422g）。D6 Max 的 16mm 已是行业天花板。如果要做差异化，10mm 固定的复刻路线风险最低 |
| 18.5W 理想电池预算 | **25W 额定功率** | PRO6 明示 25W 额定，实际需要 ±30%（32W 峰值）。60Hz 档 + 大振幅的功耗需求远超 18.5W。使用 6S LiPo 22.2V 2500mAh 方案即可 |
| 45dB 噪音目标 | **≤45dB 是完全可行的！** | NOTE6 已经做到了。关键技术：CNC 精加工传动 + 日本进口静音轴承 + 动平衡。我们之前低估了倍益康的工艺能力 |
| "双轴传动"要重新设计 | **直接照搬 NOTE6 架构即可** | 电机轴 + 从动支撑轴的"双轴"设计合理有效，不需要重新发明 |
| 固定振幅 vs 可变振幅 | **如果要做差异化，必须上可变振幅** | 这是倍益康的专利护城河，但国内可能有一些专利空白区域可以规避。如果只是复刻 PRO6，固定振幅足够 |

### 9.1 核心结论

1. **倍益康是筋膜枪行业的"隐形冠军"**——医疗 DMS 技术下沉消费级，2022-2025 年连续三年中高端全球销量第一，筋膜枪专利数全球第一，可变振幅专利数 > 第 2-10 名之和。

3. **机构方案终局**：偏心轮 + 金属活塞杆 + CNC 滑套 + 双轴传动（电机驱动轴 + 从动支撑轴）+ 日本进口静音轴承。这套架构已被倍益康 M2/NOTE6/PRO6 三代产品验证。

5. **性能规格修正**：35/40/45/50/55 Hz 五档比 15-60Hz 连续调频更合理；25W 额定功率比 18.5W 理想预算更接近实际；≤45dB 噪音是可实现的目标（NOTE6 已做到）。
