# DMS 项目总提示词 — 机械逆向研究 · 工程样机 · 性能验证 · 量产规划

## 项目身份

- **参考设备**: Dr. Fuji DMS PRO6
- **设备类型**: 深层肌肉机械刺激仪（DMS）
- **工作原理**: 电机驱动机械执行机构产生周期性往复冲击或机械振动
- **排除**: 压力波发生器 / 超声换能器 / 电极刺激
- **研究方法**: 公开资料调查 + 证据分级 + 候选架构 + 工程计算 + 样机研发

## 证据分级（四类信息）

- **A. 已确认事实**: 有可靠原始来源 + 可复核
- **B. 厂商宣传**: 标称数据，未独立验证
- **C. 合理工程推断**: 基于原理和类比
- **D. 待验证假设**: 需要实测或拆机确认

## 研究原则

1. 不虚构原机内部结构（轴系/偏心/连杆/轴承规格均为候选假设）
2. 不把宣传参数视为实测结果
3. 所有关键结论标注类别/依据/置信度/验证方式
4. 区分候选模型与原机真实结构

## 八项任务结构

1. 公开资料调查与证据管理
2. 机械逆向研究与候选架构
3. 完整动力学与驱动计算
4. 机械设计、材料与制造方案
5. 性能冲突分析与优化
6. 电池、续航、重量与噪声
7. 工程样机研发里程碑（8阶段）
8. 测试验证体系（12类测试）

## 动力学核心公式

- 峰值速度: v_max = 2πfA
- 峰值加速度: a_max = (2πf)²A
- 惯性力: F_inertia = m_eff × a（简化关系）
- 电池能量: E = V × Ah
- 理想平均功率: P_avg = E / t_hours

## Fusion 2026+ API 关键适配

- `.sketches.add(plane)` 不是 `.sketches.create()`
- `.allComponents` 不是 `.components`
- `.addNewComponent(Matrix3D)` 只接受一个参数
- `.addSimple(profile, ValueInput, op)` 不是 `.add(profile, DistanceExtentDef, op)`
- `saveAs(name, folder, desc, version)` 4 参数
- `UserParameters.add(name, ValueInput.createByReal(val), units, comment)`
