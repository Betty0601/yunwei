## 1. 编码规则

采用三级数字编码体系：`领域编号.阶段编号.工作包编号`

```
X.Y.Z
 │ └── 该阶段内的第 Z 个工作包
 └────── 所属研发阶段（0=管理, 1=需求, 2=系统, 3=详细设计, 4=验证, 5=试产, 6=注册, 7=关闭）
 └────── 所属领域（1-9，见第 2 节）
```

## 5. 工作包状态追踪

### 5.1 状态定义

| 状态 | 含义 |
|------|------|
| ⬜ 待启动 (Pending) | 依赖未满足 |
| 🟡 进行中 (In Progress) | 正在执行 |
| 🔵 已完成 (Done) | 输出就绪但未验收 |
| ✅ 已验收 (Accepted) | 通过验收标准 |
| ❌ 阻塞 (Blocked) | 遇到问题无法继续 |
| ⏸️ 暂停 (On Hold) | 非当前优先级 |

### 5.2 追踪方式

- **粒度**：每个工作包一个追踪项
- **更新频率**：每周至少一次
- **记录位置**：`docs/stage{N}/wbs/WBS_Status.md`
