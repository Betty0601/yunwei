## 1. 项目背景

### 1.1 领域定义

本项目聚焦于**专业级深层肌肉机械刺激仪**的研发。设备的核心工作原理为：**电机驱动治疗头产生周期性机械冲击或振动**，通过物理接触将机械能传递至目标肌肉组织，实现放松、激活与康复治疗效果。

### 1.2 领域排他声明

以下技术路径**明确排除**于本项目之外，不在研发范围内：

| 排除类型 | 说明 |
|----------|------|
| 压力波发生器型 (Pneumatic Percussion / Blast) | 依赖压缩气体或电磁线圈驱动的冲击波装置 |
| 超声换能器型 (Ultrasound Transducer) | 利用压电效应产生超声波的深部热疗设备 |
| 电极刺激型 (Electrical Muscle Stimulation, EMS) | 通过皮肤电极传递电流的神经肌肉刺激设备 |

本项目的本质区别在于：**直接机械驱动治疗头的物理运动**，而非声、电、气等能量形式的间接传递。

### 1.3 项目阶段说明

当前处于**阶段 0：项目定义与研发管理体系**。本阶段不涉及任何产品硬件或软件的详细设计，目标是建立可执行的研发治理框架，确保后续各阶段的输出受控、可追溯、可验证。

### 3.2 排除范围 (Out of Scope)

**关键声明：阶段 0 不预先确定任何产品参数**

| 排除项 | 理由 |
|--------|------|
| 电机规格（型号/功率/转速） | 需在阶段 2 通过技术选型确定 |
| 治疗头行程/频率/接触力 | 需基于临床需求与力学分析综合确定 |

| 公差配合/表面处理工艺 | 属于可制造性设计阶段输出 |
| 临床疗效声明/临床试验设计 | 属于法规注册阶段 |
| 固件/嵌入式软件开发 | 需硬件需求稳定后启动 |
| BOM 成本估算 | 缺乏设计输入，估算无意义 |

### 5.2 决策层级

```

L2 变更控制 ──── 已冻结基线的变更（通过 CCB）
L3 执行决策 ──── 日常执行中的技术选择（AI 角色自主，但需记录）
```
