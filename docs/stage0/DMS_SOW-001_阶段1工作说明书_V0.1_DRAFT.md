## 1. 阶段 1 概述

### 1.1 阶段目标

通过系统的市场研究、技术专利扫描、法规标准梳理，结合用户需求调研，产出**产品需求规格书 (PRS)**，并冻结**需求基线 (BL-1)**，为阶段 2 系统设计提供明确输入。

### 1.2 阶段范围

| 纳入 | 排除 |
|------|------|
| 目标用户画像与需求 | 详细技术方案（阶段 2） |
| 竞品分析 | CAD 建模（阶段 3） |
| 法规合规框架 | 样机试制（阶段 5） |
| 专利风险扫描 | 固件开发 |
| 产品需求规格书 | 临床方案 |
| 可行性评估 | 供应链选择 |

### 1.3 预计周期

**4-6 周**（自门 G0→G1 通过之日起）

#### PRS 结构要求

```
1. 引言
2. 范围与排除（引用 PR-001）
3. 用户需求 (UR)
4. 产品需求 (PR)
   4.1 功能需求
   4.2 性能需求（频率/冲击力/行程/效率等范围值，不冻结）
   4.3 安全需求
   4.4 环境需求
   4.5 寿命与可靠性需求
   4.6 合规需求
5. 假设与约束
6. 术语表
7. 附录：RTM
```
