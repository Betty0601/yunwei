# DMS-P2-03 初步动力学与载荷分析计划

## 1. 动力学研究目标

动力学分析的核心不是简单计算一个理论冲击力，而是建立驱动系统、运动机构、支撑结构和外部接触负载之间的力学关系。

应重点回答：
- 驱动机构需要提供多大的转矩或推力？
- 运动部件产生的惯性载荷有多大？
- 外部接触负载如何影响电机速度和机构响应？
- 哪些零件承担周期性载荷？
- 哪些载荷可能导致疲劳、松动、磨损或变形？
- 是否存在共振、冲击放大或接触失稳？
- 哪些参数可以计算，哪些必须测量？
- 如何把模型结果转化为可验证的工程要求？

## 2. 动力学模型的层级与假设

### 2.1 刚体单自由度模型
将输出机构等效为一个运动质量 $m_{\mathrm{eq}}$，输出位置为 $x$：
$$m_{\mathrm{eq}}\ddot{x} = F_{\mathrm{drive}} - F_{\mathrm{load}} - F_{\mathrm{friction}}$$
适合初步研究惯性载荷、外部负载与驱动能力的关系。**不适合直接证明复杂冲击过程中的瞬时峰值载荷** — 真实接触可能包含高频弹性波、局部接触变形、间隙闭合和非线性材料响应。

### 2.2 旋转系统模型
$$J_{\mathrm{eq}}\dot{\omega} = T_{\mathrm{motor}} - T_{\mathrm{load}} - T_{\mathrm{loss}}$$
$J_{\mathrm{eq}}$ 单位 kg·m²，所有转矩均需折算到同一根参考轴。

电机速度恒定时 $\dot{\omega} \approx 0$，稳态 $T_{\mathrm{motor}} \approx T_{\mathrm{load}} + T_{\mathrm{loss}}$。但周期运动设备即使平均转速近似恒定，也可能存在周期性转矩脉动 — 平均转矩不能代替峰值转矩分析。

### 2.3 多自由度动力学模型
对于曲柄、连杆、滑块、弹簧等耦合系统，采用广义坐标：
$$\mathbf{q} = [q_1\ q_2\ \cdots\ q_n]^T$$
$$\mathbf M(\mathbf q)\ddot{\mathbf q} + \mathbf C(\mathbf q,\dot{\mathbf q})\dot{\mathbf q} + \mathbf G(\mathbf q) + \mathbf f(\mathbf q,\dot{\mathbf q}) = \mathbf Q_{\mathrm{act}} + \mathbf Q_{\mathrm{ext}}$$
- $\mathbf M$：质量矩阵
- $\mathbf C$：速度相关的惯性项或科氏项矩阵
- $\mathbf G$：重力或其他保守力项
- $\mathbf f$：摩擦、阻尼及其他非保守力项
- $\mathbf Q_{\mathrm{act}}$：广义驱动力
- $\mathbf Q_{\mathrm{ext}}$：外部广义载荷

矩阵必须根据实际机构推导，不能直接套用符号而不定义各项。

## 3. 往复运动惯性载荷

### 基本关系
$$F_{\mathrm{inertia}} = ma$$
多部件系统：
$$F_{\mathrm{inertia,total}}(t) = \sum_{i=1}^N m_i a_i(t)$$
只适用于沿同一方向可直接相加的惯性力分量。若部件运动方向不同，必须进行矢量分解。

对旋转部件需考虑转动惯量和角加速度；对连杆等同时平动和转动的部件，需同时考虑质心运动与转动惯性。

### 运动质量管理
CAD 模型应能提供各零件的质量、质心位置、惯性张量、材料密度来源、运动副和约束关系、运动轨迹。但 CAD 质量属性只有在材料、密度和几何均合理时才有意义 — 不能把尚未定义材料的概念实体质量直接当作最终动力学输入。

### 反作用力与平衡
往复运动部件会对机架产生反作用载荷。反作用力的具体方向和大小应根据自由体图与机构运动关系计算。不能简单地认为电机转子平衡就代表整机没有振动 — 往复质量、连接件弹性、结构模态和外部接触仍可能产生明显振动响应。

## 4. 驱动转矩与功率需求

理想旋转输入：$P = T\omega$。当转矩和速度随时间变化时：
$$P(t) = T(t)\omega(t)$$

应区分：
- 平均机械功率
- 周期性峰值机械功率
- 电机电输入功率
- 驱动器损耗
- 电机铜损与铁损
- 传动摩擦损失
- 结构或弹性组件的储能与耗能

根据虚功原理建立输入转矩与输出力的关系：$T d\theta = F dx$，理想准静态条件下：
$$T = F\frac{dx}{d\theta}$$

这说明：输入转矩需求取决于输出力与机构的瞬时几何传动关系 — 不能只用某个固定传动比代表整个往复周期的动态负载。实际机构需考虑传动效率、惯性项、摩擦和接触动态载荷。

## 5. 接触载荷与冲击过程

### 为什么不能直接用 $F=ma$ 完成
治疗头与外部接触对象之间的接触过程可能同时存在：运动部件惯性、接触表面弹性变形、外部对象黏弹性响应、预压力、接触分离、结构柔性、传感器和支撑系统动态响应、局部接触几何变化。因此，**运动部件的惯性力不等于治疗头对接触对象的瞬时作用力。**

接触力需依据完整动力学模型、适当的接触关系以及必要的实测数据确定。

### 线性接触刚度概念模型
在有限范围内，若接触对象可近似为线性弹性系统：
$$F_c = k_c \delta$$
若加入线性黏性阻尼：
$$F_c = k_c \delta + c_c \dot{\delta}$$
限制在接触保持成立的时间区间内，并根据实际接触状态处理分离条件。

**该模型不代表人体组织具有固定线性刚度。** 人体组织力学响应受组织类型、几何、加载速度、预压、时间和个体差异影响。

### 冲量与平均力
冲量：
$$J = \int_{t_1}^{t_2} F_c(t)\,dt \quad (\text{单位 N·s})$$
平均力：
$$F_{\mathrm{avg}} = \frac{1}{t_2 - t_1}\int_{t_1}^{t_2} F_c(t)\,dt$$
平均力不能代表峰值力。

接触事件动态特征应保存完整力—时间曲线，并根据目标定义提取：峰值接触力、接触持续时间、冲量、加载速率、卸载速率、事件间隔、事件重复性、接触期间的位移和速度。这些量必须通过定义明确的测试方法获取，不能从空载电机转速直接推算。

## 6. 载荷工况定义

| 工况编号 | 工况 | 研究目的 | 必要输入 |
|---|---|---|---|
| LC-01 | 静止、无外载 | 检查初始结构与装配状态 | 质量、几何、安装约束 |
| LC-02 | 空载周期运行 | 建立基准运动与振动特征 | 转速、行程、运动部件质量 |
| LC-03 | 规定外部阻力 | 研究持续负载影响 | 外载模型、速度、周期 |
| LC-04 | 规定接触刚度 | 研究接触状态变化 | 接触模型、预压和接触条件 |
| LC-05 | 规定工作周期 | 研究热积累与持续运行 | 运行时间、负载、环境条件 |
| LC-06 | 启动与停止 | 检查加速、减速和瞬态载荷 | 控制轨迹、转动惯量 |
| LC-07 | 运动受阻 | 检查堵转、卡滞及异常载荷 | 故障模型、保护响应 |
| LC-08 | 关键连接松动或间隙变化 | 研究异常动态与耐久风险 | 间隙假设、连接刚度 |
| LC-09 | 治疗头偏心或侧向加载 | 检查导向与支撑侧向载荷 | 偏载位置、方向、幅值依据 |
| LC-10 | 长期重复循环 | 疲劳与磨损评估 | 周期数、载荷谱、材料数据 |

**LC-03、LC-04、LC-05、LC-07 等工况的定量输入尚未确定，必须由后续需求、风险分析和试验计划给出。**

## 7. 疲劳与寿命分析计划

周期性运动设备可能存在大量重复载荷 — 即使静强度满足要求，也不能自动证明长期寿命满足要求。

### 需要关注的部件
- 偏心轴
- 曲柄和曲柄销
- 连杆
- 输出杆
- 导向件
- 轴承和轴承座
- 治疗头连接结构
- 紧固件
- 弹簧
- 壳体的局部连接区域

### 疲劳分析输入
每个关键零件至少需要：
- 几何与截面信息
- 材料牌号和材料状态
- 真实载荷方向
- 应力集中因素
- 表面加工状态
- 热处理状态
- 装配预紧或残余应力
- 腐蚀、润滑和环境条件
- 目标循环数
- 载荷变化与异常载荷谱

对于变幅载荷，不能仅以一个最大载荷代替完整载荷谱。必要时应采用适合材料和载荷条件的疲劳方法，并说明其适用性与局限性。

### 生命周期的定义
项目应区分：设计目标寿命、预期使用频率、单次使用时间、每日或每周的工作周期、维护周期、易损件更换周期、设计验证循环数、可靠性试验循环数。这些指标必须通过产品定义与风险分析确定 — 当前不得自行设定为最终要求。
