# DMS-P2-01 机械原理候选方案研究报告

## 1. 研究范围与前提

本报告对深肌机械刺激仪可采用的 6 类候选机械架构进行概念层面的原理研究。所有结论均为 `ESTIMATE` 或 `ASSUMPTION`，尚未通过正式输入、实体样机或实测数据验证。

候选架构按运动转换原理分组：
- A：旋转电机 + 偏心驱动
- B：旋转电机 + 曲柄连杆
- C：旋转电机 + 凸轮
- D：旋转电机 + 齿轮/同步带等复合传动 + 运动转换
- E：直接驱动直线执行机构
- F：旋转电机 + 弹性储能/缓冲组件（作为跨方案辅助功能模块）

## 2. 方案 A：旋转电机 + 偏心驱动机构

### 工作原理
旋转电机驱动偏心轴或偏心轮旋转，偏心点通过连接件把旋转运动转换成周期性往复运动。常见实现：偏心销直接驱动滑块、偏心轮配合滑动导向、偏心轮通过连杆驱动输出杆、偏心驱动 + 独立导向组合。

动力路径：旋转电机 → 偏心轴/偏心轮 → 滑块或连杆组件 → 直线导向与输出杆 → 治疗头执行组件。

### 运动学特征
在理想偏心投影模型下：
- 位置：$x(t) = x_0 + e\cos(\omega t + \phi)$
- 速度：$v(t) = -e\omega\sin(\omega t + \phi)$
- 加速度：$a(t) = -e\omega^2\cos(\omega t + \phi)$
- 行程：$S = 2e$
- $v_{\max} = e\omega$，$a_{\max} = e\omega^2$，$j_{\max} = e\omega^3$

若机构含连杆、摆杆或滑槽，输出不再是严格正弦，需建立真实几何关系。

### 优势
- 运动规律易建模，行程与偏心距直接关联。
- 旋转电机和轴承零件供应链成熟。
- 较少控制自由度即可实现周期性往复。
- 适合参数化 CAD 对偏心距、连杆长度、安装位置开展概念研究。

### 局限
- 运动规律由机械几何决定，不能仅靠调转速改变运动波形。
- 往复质量产生周期性惯性载荷。
- 偏心轴、轴承和支撑结构承受周期性反力。
- 不平衡可能把振动传递到手柄和壳体。
- 润滑、磨损、间隙和噪声需评估。
- 单纯偏心往复不能自动保证分离式冲击过程。

### 失效模式
- 偏心轴疲劳
- 轴承磨损或过热
- 偏心销与连接件间隙增长
- 导向件卡滞
- 紧固件松动
- 往复质量引起的结构振动
- 治疗头连接件疲劳或脱落
- 电机负载变化导致速度波动
- 润滑失效造成温升和摩擦增加

### 适用性判断
适合作为重点研究候选，尤其适用于需要规则周期性往复运动、控制目标不要求高度自由波形调节的场景。在实际输出载荷、噪声、质量、温升和连续工作要求未明确前，不能仅凭机构简单就定为最终方案。

## 3. 方案 B：旋转电机 + 曲柄连杆机构

### 工作原理
电机带动曲柄旋转，曲柄通过连杆连接滑块或输出杆，将旋转运动转换为直线往复运动。

### 运动学特征
中心线曲柄滑块布置：$x(\theta) = r\cos\theta + \sqrt{l^2 - r^2\sin^2\theta}$

- 几何可行性要求 $l^2 - r^2\sin^2\theta \ge 0$
- 速度 $v = \omega \cdot dx/d\theta$，加速度 $a = \omega^2 \cdot d^2x/d\theta^2$（恒速）
- 输出波形受 $r/l$ 比例影响，非严格正弦

### 优势
- 运动关系明确，便于建立完整机构模型。
- 曲柄、连杆、销轴、滑块有成熟工程实现。
- 可通过改变几何比例调整运动波形。
- 适合 Fusion 360 组件、关节、运动关系进行概念检查。
- 可与独立导向、复位、限位组合。

### 局限
- 铰接点数量通常多于简单偏心滑块。
- 铰接间隙、摩擦、润滑和装配公差增加维护需求。
- 连杆摆角产生侧向分力。
- 某些转角位置的机械力传递特征可能使局部载荷增大。
- 高速周期运动下铰接和导向耐久性需重点验证。

### 载荷路径
电机转子 → 曲柄轴 → 曲柄销 → 连杆 → 滑块或输出杆 → 治疗头。反作用力通过滑块导向、曲柄轴承和支撑结构返回壳体。

### 适用性判断
应作为偏心驱动的重要对照候选，尤其当输出运动波形、空间布置或载荷传递路径对设计有明显影响时。

## 4. 方案 C：旋转电机 + 凸轮机构

### 工作原理
旋转电机驱动凸轮旋转，凸轮轮廓与从动件接触，将旋转运动转换为规定的输出位移。可实现规定的升程、停歇区间、回程和非正弦位移规律。

### 运动学特征
- $s = s(\theta)$，在角速度恒定时 $v = \omega \cdot ds/d\theta$，$a = \omega^2 \cdot d^2s/d\theta^2$，$j = \omega^3 \cdot d^3s/d\theta^3$
- 加加速度 $j$ 对高动态运动的振动、接触载荷变化和机构激励有重要影响

### 优势
- 可灵活定义位移随转角的变化规律。
- 适合需要特定升程、停歇或回程特性的机械运动。
- 重复性好的几何运动。
- 运动规律设计可作为参数的一部分进行优化。

### 局限
- 凸轮轮廓设计与加工要求较高。
- 从动件与凸轮接触应力、润滑和磨损需专门分析。
- 高速时惯性载荷可能导致从动件失去持续接触。
- 弹簧预紧结构引入额外载荷和寿命问题。
- 轮廓修改导致零件制造和验证成本增加。

### 失效模式
- 凸轮表面疲劳或磨损
- 从动件滚轮或滑动接触副损坏
- 预紧结构疲劳
- 润滑不足
- 高速条件下接触失稳
- 轮廓误差导致运动规律偏离
- 接触力峰值超出结构或材料能力

### 适用性判断
若阶段 1 需求表明输出运动规律需要专门设计，值得深入研究；否则不宜仅因凸轮能生成复杂运动就优先选择。

## 5. 方案 D：旋转电机 + 复合传动

### 工作原理
电机通过齿轮、同步带、减速机构等，将动力传递到偏心、曲柄或凸轮机构。是速度转换、转矩匹配与运动转换组成的复合架构。

### 运动学特征
- 外啮合齿轮副转速比 $n_2/n_1 = -z_1/z_2$
- 减速比 $i = |n_{\mathrm{in}}/n_{\mathrm{out}}|$
- 稳态转矩 $T_{\mathrm{out}} \approx \eta i T_{\mathrm{in}}$

### 优势
- 将电机工作点调整到更合适的速度—转矩范围。
- 电机布置位置灵活。
- 可与偏心、曲柄、凸轮形成组合方案。

### 局限
- 增加传动零件、轴承、连接件和装配步骤。
- 齿隙、润滑、磨损影响动态响应。
- 额外传动级增加噪声和机械损失。
- 效率和温升需根据具体器件确认。

### 适用性判断
只有在电机本身转速、转矩、安装空间或控制性能无法满足要求时，才应进一步评估。转矩提升必须与速度、效率、尺寸、惯量和热负荷共同评估。

## 6. 方案 E：直接驱动直线执行机构

### 工作原理
执行器直接产生直线运动，不再通过旋转电机与传统机械运动转换机构。候选形式包括电磁直线执行器、具备位置控制的直线伺服等。

### 动力学特征
$m\ddot{x} = F_{\mathrm{act}} - F_{\mathrm{load}} - F_{\mathrm{friction}}$

（忽略结构弹性、非线性摩擦、电磁动态、控制延迟和接触瞬态。）

### 优势
- 可能减少传统机械运动转换零件。
- 更直接地调节位移、速度和运动波形。
- 减少部分齿轮、偏心销或连杆间隙。
- 适合对位置反馈和输出可调性要求较高的架构。

### 局限
- 峰值力、连续力、行程、速度和热性能必须同时满足。
- 可能存在较高瞬时电流和热负荷。
- 直接驱动不意味着没有振动、摩擦或结构共振。
- 力常数、反电动势、线圈温升和驱动器要求需依据具体技术资料。
- 成本、体积和散热能力可能限制可行性。

### 适用性判断
如果产品定义强调可调运动规律、闭环位置控制或负载下的运动一致性，值得作为对照方案。

## 7. 方案 F：弹性储能/缓冲组件（跨方案功能模块）

### 工作原理
在基本驱动机构之外增加弹簧、弹性体、缓冲件等，用于改变输出力—位移关系、吸收部分能量或降低某些载荷峰值。需严格区分三种功能：复位、缓冲、储能与释放。

### 特征
- 线性弹簧 $F_s = kx$，储能 $E_s = \frac{1}{2}kx^2$
- 线性黏性阻尼 $F_d = c\dot{x}$
- 真实弹性体具有非线性、滞回、温度依赖、频率依赖和长期蠕变特性

### 优势
- 改善复位稳定性
- 改变系统刚度和动态响应
- 缓冲组件帮助降低某些局部接触峰值
- 为输出杆提供一定机械顺应性

### 局限
- 引入新的固有频率和共振风险
- 复位弹簧增加驱动负荷
- 弹簧疲劳、松弛、腐蚀和弹性体老化需验证
- 过度依赖弹性储能可能造成不可预测的瞬态输出
- 弹性组件不能自动保证人体接触力安全

### 适用性判断
应视为跨方案的功能模块，不是默认加入所有设计的标准部件。是否需要、采用何种结构及其对输出的影响，必须由运动链、载荷模型和风险分析共同决定。

## 9. 研究优先级建议

在正式需求缺失的情况下，合理策略不是立刻选定唯一方案，而是建立分层比较：

- **第一组：** 偏心机构与曲柄连杆机构 — 传统旋转—往复转换的主要比较对象。
- **第二组：** 凸轮机构 — 用于检验是否需要特殊运动规律。
- **第三组：** 直线直驱 — 用于检验更直接的运动控制是否能满足需求。
- **条件性组合：** 齿轮或其他传动级、复位弹簧、阻尼或缓冲组件 — 根据第一轮模型结果决定是否纳入更深入分析。

这样可以避免把所有可能的机械零件无差别组合，导致架构复杂化。

## 10. 状态声明

本报告所有架构均处于 `ASSUMPTION` 或 `ESTIMATE` 状态。由于正式输入文件尚未提供，任何具体电机型号、运动行程、冲击力、工作频率、治疗头尺寸、材料牌号或人体接触参数均不认定为最终设计值。

本阶段的目标是确定**应该比较什么、如何比较、采用什么模型、如何验证，以及哪些结论足以支持下一阶段**，而不是提前完成尚缺少设计输入的详细机械设计。
