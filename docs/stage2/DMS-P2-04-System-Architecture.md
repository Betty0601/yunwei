# DMS-P2-04 系统架构与功能分解说明书

## 1. 系统架构设计原则

系统架构围绕**功能、接口、载荷、运动约束和维护需求**建立。

能量链：
1. 电源与电机驱动器 — 电能输入、功率调节、驱动保护
2. 电机及其转子或直线运动部件 — 产生旋转或直线运动
3. 机械运动转换与传动机构 — 偏心、连杆、凸轮、直驱或其他经评估的架构
4. 导向、支撑与治疗头执行组件 — 运动约束、载荷传递、限位和防脱
5. 人体接触界面 — 接触载荷、组织响应、反作用力和热传递

功能分解的目的是明确责任和接口，而不是增加零件数量。并非每个子系统都必须由独立零件或独立模块组成。

## 2. 功能架构图

```
  A. 电源与驱动系统        (电源输入、驱动器、保护和控制接口)
         │
         ▼
  B. 动力源                (旋转电机或经评估的直线执行器)
         │
         ▼
  C. 机械运动转换          (偏心、曲柄、凸轮或其他批准方案)
         │
         ▼
  D. 输出导向、支撑及限位  (运动约束、载荷闭合、行程限制)
         │
         ▼
  E. 治疗头与接触界面      (输出位移、接触状态、可更换接口)

横向支持：传感与控制、热管理、结构防护、维护接口、验证与数据采集。
```

## 3. 子系统定义（SYS-01 ~ SYS-10）

### SYS-01：动力源与驱动系统
**功能**：根据批准的控制要求，为机械执行机构提供所需动力。

输入：电源、控制命令、位置/速度/电流/温度反馈（若适用）。
输出：机械转矩或直线推力、状态信息、故障与保护信号。

待确认参数：
- 电机类型
- 额定与峰值工作条件
- 转速或行程需求
- 控制带宽
- 工作周期
- 驱动器接口
- 冷却方式
- 允许温升

设计原则：
- 电机选择必须以负载模型和工作周期为依据
- 必须检查连续能力与瞬态能力
- 必须定义启动、停止、过载和卡滞情况下的响应
- 必须明确传感器与驱动器之间的数据接口

### SYS-02：机械运动转换系统
**功能**：将动力源运动转换为所需输出运动。

主要候选：偏心机构、曲柄连杆、凸轮机构、直线直驱、经论证的复合机构。

接口：输入轴或执行器连接接口、输出杆或从动件接口、机架固定接口、轴承或导向接口、位置或转速测量接口。

设计原则：
- 明确运动自由度
- 明确输入输出运动关系
- 识别运动极限位置
- 识别可能的卡滞位置
- 建立周期载荷路径
- 确定润滑、维护与检查要求

### SYS-03：输出导向与支撑系统
**功能**：约束输出运动方向，承担必要的侧向载荷，并维持装配关系。

主要组成可能包括：直线导向件、轴承或衬套、轴承座、支撑框架、输出杆支撑件。

关键接口：导向轴线、安装基准面、支撑跨距、配合关系、轴向与径向限位、润滑与密封接口。

必须通过载荷模型和公差分析确认导向结构，不能仅依据外观布局确定。

### SYS-04：治疗头执行组件
**功能**：将输出运动传递到可更换或固定的治疗头。

必须研究：治疗头与输出杆的连接形式、轴向防脱、旋转或侧向自由度是否允许、装配重复性、接触端几何、清洁与维护方式、更换操作的防错设计、连接结构的疲劳与磨损。

对于可更换治疗头，不同治疗头可能改变质量、惯量、接触面积或输出动态特征 — 不同附件不能默认具有相同的动力学表现。

### SYS-05：复位、缓冲与限位系统
**功能**：在需要时提供复位、限制运动范围或改变动态响应。

候选组成：机械止挡、弹性复位件、缓冲组件、可调或固定限位结构、位置检测接口。

必须明确：正常运动的允许范围、极限位置、超行程时的行为、限位件是否承担重复动态载荷、限位件失效后的风险、复位机构是否可能储存危险能量、维护和更换要求。

### SYS-06：机架与外壳系统
**功能**：提供结构支撑、保护内部运动件，并形成可握持的产品外形。

必须区分：承载机架、电机安装结构、轴承支撑结构、外部防护壳体、握持表面、检修盖与维护开口。

外壳不应未经分析就承担主要的周期载荷。若采用壳体作为结构承载件，必须明确其材料、连接和强度设计依据。

### SYS-07：热管理系统
**功能**：控制关键部件和接触界面的温度，使其满足经批准的安全与性能要求。

候选功能：导热路径设计、散热结构、热隔离、温度监测、驱动器热保护、热源与握持区域的空间隔离。

热管理方案必须与壳体设计、通风条件、密封要求和电气安全共同研究。

### SYS-08：传感与控制接口
**功能**：提供所需的运动、负载、温度和状态信息。

候选传感量：
- 电机转速、转子位置
- 输出杆位移、输出接触力
- 电机电流、电机温度、驱动器温度
- 壳体关键位置温度
- 振动
- 治疗头连接状态（若有必要）

不是所有传感器都必须集成到最终产品中，需根据可控性、风险控制和验证需求确定。

### SYS-09：电气连接与线缆管理
**功能**：提供可靠的电源与信号连接，避免线缆干涉运动机构。

需要研究：线缆路径、最小弯曲半径、应力释放、与运动件的间隙、与热源的距离、接插件固定、维修可达性、装配错误预防、线缆磨损与疲劳。

### SYS-10：防护与维护系统
**功能**：降低可预见的机械、电气和热相关风险，并支持检查与维修。

需要定义：运动部件防护、夹伤风险区域、维修时的能源隔离、易损件更换方法、维护检查项目、关键连接件的检查方式、维护后复测要求、维修与更换记录。

## 4. 组件层级建议（DMS-100 ~ DMS-700）

```
DMS-000：顶层总装 (DMS_Main_Assembly)
  ├── DMS-100：驱动组件       (电机、安装座、驱动轴接口)
  ├── DMS-200：运动转换组件   (偏心、曲柄或凸轮候选组件)
  ├── DMS-300：导向与输出组件 (输出杆、导向件、支撑件、限位件)
  ├── DMS-400：治疗头组件     (连接接口、治疗头与防脱件)
  ├── DMS-500：机架组件       (主要载荷支撑和定位基准)
  ├── DMS-600：外壳与握持组件 (防护、握持、检修盖与线缆出口)
  └── DMS-700：传感与热管理接口 (传感器安装位、热路径与线缆通道)
```

这是逻辑层级建议。某些组件可以合并，某些组件也可能进一步拆分。例如：若最终采用直线直驱机构，DMS-200 的结构可能与旋转电机方案完全不同；若没有独立弹性组件，则不应为了满足组件树而创建虚假的弹簧零件。

## 5. 关键接口控制文件（ICD-001 ~ ICD-012）

接口控制文件（ICD）应成为机械、控制、电气、热设计和 CAD 建模之间的共同依据。

| 接口编号 | 接口名称 | 需要定义的内容 | 主要验证方式 |
|---|---|---|---|
| ICD-001 | 电机—机架 | 安装基准、紧固、载荷、空间 | 装配检查、强度分析 |
| ICD-002 | 电机—传动 | 轴径、连接、对中、传动关系 | 尺寸检查、运动测试 |
| ICD-003 | 传动—输出杆 | 运动关系、连接和载荷路径 | 运动学与载荷验证 |
| ICD-004 | 输出杆—导向 | 轴线、间隙、长度、润滑 | 配合检查、摩擦测试 |
| ICD-005 | 输出杆—治疗头 | 连接、限位、防脱和维护 | 拉脱、耐久与装配测试 |
| ICD-006 | 机架—壳体 | 定位、固定、检修空间 | 装配与结构检查 |
| ICD-007 | 电机—驱动器 | 电气接口、控制信号、保护 | 电气测试 |
| ICD-008 | 传感器—控制器 | 量程、采样、精度、接口 | 标定与数据采集测试 |
| ICD-009 | 热源—壳体 | 导热路径、热隔离、温度监测 | 热分析与热测试 |
| ICD-010 | 线缆—运动机构 | 走线、弯曲、运动间隙 | 运动包络与耐久测试 |
| ICD-011 | 治疗头—接触对象 | 接触几何、负载和测量条件 | 受控台架测试 |
| ICD-012 | 维护模块—整机 | 拆装空间、复装要求、检查点 | 维修演练与复测 |

每个接口应记录：接口编号、发送方和接收方、几何基准、机械约束、载荷范围及来源、运动自由度、电气或信号要求、热边界条件、制造公差、检查方法、责任人、当前状态、变更历史。

**在关键接口未定义之前，不宜开展依赖该接口的精细零件设计。**
