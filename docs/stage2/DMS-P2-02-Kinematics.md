# DMS-P2-02 候选方案运动学分析报告

## 1. 统一运动学变量与定义

为了保证不同候选机构可以在相同的工程语言下比较，必须建立统一的变量体系。

| 符号 | 名称 | 单位 | 说明 |
|---|---|---|---|
| $t$ | 时间 | s | 运动分析的时间变量 |
| $\theta$ | 电机或机构转角 | rad | 必须明确对应哪根轴 |
| $\omega$ | 角速度 | rad/s | $\omega = d\theta/dt$ |
| $\alpha$ | 角加速度 | rad/s² | $\alpha = d\omega/dt$ |
| $n$ | 转速 | r/min | 必须注明测量轴 |
| $f_r$ | 旋转频率 | Hz | 对应转速的旋转循环频率 |
| $f_o$ | 输出运动频率 | Hz | 必须定义完整运动周期 |
| $x$ | 输出位移 | m | 应说明参考位置和正方向 |
| $S$ | 完整行程 | m | 两个极限位置之间的距离 |
| $v$ | 输出速度 | m/s | $v = dx/dt$ |
| $a$ | 输出加速度 | m/s² | $a = d^2x/dt^2$ |
| $j$ | 输出加加速度 | m/s³ | $j = da/dt$ |
| $m$ | 等效运动质量 | kg | 应明确包含哪些零件 |
| $F$ | 力 | N | 必须区分惯性力、驱动力和接触力 |
| $T$ | 转矩 | N·m | 必须注明轴的位置 |
| $P$ | 功率 | W | 机械功率与电输入功率应分开 |

所有计算文件中应同时保存符号、单位、参数来源、当前状态和允许修改范围。禁止只保存无单位的数字。

## 2. 转速、运动频率与接触事件频率关系

电机转速与转频的关系为：
$$f_r = \frac{n}{60}$$
其中 $n$ 单位 r/min，$f_r$ 单位 Hz。

对于一个电机转动周期恰好产生一个完整输出往复周期的机构，在没有额外传动级、失步或特殊运动关系的理想条件下：
$$f_o = f_r$$

若每转产生 $k$ 个完整输出运动周期，则：
$$f_o = kf_r$$
$k$ 必须由实际机构几何关系确定，不能根据设备名称猜测。

### 重要约束
$$f_o \ne f_{\mathrm{contact}} \quad \text{（不能默认相等）}$$
实际接触事件频率 $f_{\mathrm{contact}}$ 取决于接触状态、运动轨迹、预压量、外部负载和接触分离过程。

### 频率的工程定义
项目中应至少区分：
- 电机旋转频率
- 传动轴旋转频率
- 执行机构完整运动周期频率
- 治疗头位移信号的主频
- 实际接触事件频率
- 接触力信号的主要频率成分
- 结构振动频率及其谐波
- 声学测量中的主要频率成分

这些频率可能相关，但不能互相替代。

## 3. 运动学模型层级

不同模型具有不同用途，避免用一个简单公式承担所有工程任务。

### 一级模型：理想几何模型
**目的**：确认机构是否具有所需自由度、行程是否可通过几何参数调节、检查几何奇异位置、确定运动包络和初步安装空间、估算理想速度和加速度的参数依赖关系。

**不考虑**：间隙、弹性变形、摩擦变化、接触冲击、控制延迟、结构振动、热变形。

### 二级模型：包含驱动特性的运动模型
在一级模型基础上增加：电机速度变化、传动比、驱动器限速与限加速度、启停过程、负载对运动速度的影响、运动周期之间的变化。

变速情况使用：
$$v = \frac{dx}{d\theta}\omega(t), \quad a = \frac{d^2x}{d\theta^2}\omega^2(t) + \frac{dx}{d\theta}\alpha(t)$$
第二项表示角加速度对输出加速度的贡献。

### 三级模型：动力学耦合模型
将运动几何、质量惯量、摩擦、接触负载、驱动转矩和结构柔性纳入模型。用于研究负载变化导致的速度波动、驱动转矩峰值、运动部件惯性载荷、结构弹性对输出的影响、接触事件中的力与速度变化、系统固有频率与动态响应。

**此类分析不能仅凭 Fusion 360 装配动画完成。**

### 四级模型：实验校准模型
通过实测位移、转速、电流、力和振动数据，校准前述模型。只有测量条件、传感器带宽、数据采样、滤波方法和不确定度得到记录后，实验校准结果才可用于设计决策。

## 4. 偏心机构运动学推导

### 理想偏心投影模型
$$x(t) = x_0 + e\cos(\omega t)$$
$$v(t) = -e\omega\sin(\omega t)$$
$$a(t) = -e\omega^2\cos(\omega t)$$
$$j(t) = e\omega^3\sin(\omega t)$$

由此可得：
$$v_{\max} = e\omega, \quad a_{\max} = e\omega^2, \quad j_{\max} = e\omega^3$$

若用行程 $S = 2e$ 表示：
$$v_{\max} = \frac{S\omega}{2}, \quad a_{\max} = \frac{S\omega^2}{2}, \quad j_{\max} = \frac{S\omega^3}{2}$$

### 参数依赖关系
- 最大速度与行程、角速度成正比
- 最大加速度与行程成正比、与角速度平方成正比
- 最大加加速度与行程成正比、与角速度立方成正比

因此，提高转速不仅提高运动频率，也会以更高比例提高惯性相关的动态指标。

**注意**：这些公式不能直接推导人体接触力，也不能证明设备的机械输出符合某一临床用途。

## 5. 曲柄滑块机构运动学分析方法

### 几何约束
设曲柄长度为 $r$，连杆长度为 $l$，曲柄转角为 $\theta$，滑块位置为 $x$。

中心线曲柄滑块布置：
$$x(\theta) = r\cos\theta + \sqrt{l^2 - r^2\sin^2\theta}$$

几何可行性要求：
$$l^2 - r^2\sin^2\theta \ge 0$$

若设计参数和运动范围导致平方根内部为负，则该位置不属于此理想机构的可实现几何范围。

### 速度与加速度
若 $\omega$ 为恒定曲柄角速度：
$$v(\theta) = \omega\frac{dx}{d\theta}, \quad a(\theta) = \omega^2\frac{d^2x}{d\theta^2}$$

若角速度变化：
$$a(\theta, t) = \omega^2(t)\frac{d^2x}{d\theta^2} + \alpha(t)\frac{dx}{d\theta}$$

### 分析输出要求
每个曲柄连杆候选模型至少应生成：
1. 曲柄角度—滑块位移曲线
2. 曲柄角度—滑块速度曲线
3. 曲柄角度—滑块加速度曲线
4. 曲柄角度—连杆角度曲线
5. 连杆轴向力与侧向力的后续计算接口
6. 输出运动包络与关键位置的几何检查结果

曲线应带有单位、参数版本和计算脚本版本。不应只比较最大行程 — 两个机构即使行程相同，也可能具有不同的速度分布、加速度峰值和载荷波形。

## 6. 凸轮机构运动学分析方法

对于凸轮机构，不能只记录最大升程 $h$，还应定义整个升程函数：
$$s = s(\theta)$$

变速情况下：
$$v(\theta) = \omega\frac{ds}{d\theta}$$
$$a(\theta) = \omega^2\frac{d^2s}{d\theta^2} + \alpha\frac{ds}{d\theta}$$
$$j(\theta) = \omega^3\frac{d^3s}{d\theta^3} + 3\omega\alpha\frac{d^2s}{d\theta^2} + \dot{\alpha}\frac{ds}{d\theta}$$

### 凸轮方案需在后续分析中明确
- 升程和回程角度范围
- 是否存在停歇区
- 从动件类型
- 凸轮基圆与轮廓几何
- 接触保持条件
- 接触应力和润滑方式
- 轮廓制造公差
- 高速运动下的动态接触风险

## 7. 直线执行器运动学与控制关系

直线执行器直接以输出位置为运动变量：
$$x = x(t), \quad v = \frac{dx}{dt}, \quad a = \frac{d^2x}{dt^2}$$

跟踪周期性参考轨迹时需区分：
- 参考位移 $x_{\mathrm{ref}}(t)$
- 实际位移 $x_{\mathrm{meas}}(t)$
- 跟踪误差 $e_x(t) = x_{\mathrm{ref}}(t) - x_{\mathrm{meas}}(t)$
- 实际速度与参考速度
- 实际负载与驱动能力
- 控制器带宽和执行器动态响应

可使用峰值误差、均方根误差、周期变化和负载变化下的误差等指标评估。但这些指标的允许值必须由阶段 1 的需求规定，不能由建模人员自行确定为正式验收标准。

## 8. 运动学分析统一交付要求

所有候选方案均应提交：
- 参数定义表
- 机构自由度说明
- 运动约束方程
- 完整周期位移、速度和加速度结果
- 极限位置和运动包络
- 可能的几何奇异位置
- 理想模型与真实机构之间的差异说明
- 计算脚本及版本
- 参数敏感性分析
- 未建模因素列表
- 后续动力学模型所需的输入清单

**运动学分析通过，不代表动力学分析通过，更不代表实际输出载荷已经验证。**
