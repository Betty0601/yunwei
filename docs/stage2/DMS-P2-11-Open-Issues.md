# DMS-P2-11 尚未解决的技术问题与后续计算计划

## 1. 重大未知问题

当前最重要的未知问题不只是某个尺寸，而是**哪些产品要求将决定整个机构架构**。

### 1.1 产品定义

需要确认：
- 设备的正式预期用途
- 目标用户
- 专业场景或其他使用场景
- 目标市场
- 是否涉及医疗用途声明
- 允许的工作环境
- 产品形态与握持方式
- 维护和清洁要求
- 目标价格与成本
- 预期寿命

这些问题会影响机械设计、风险分析、材料、控制和法规路径。

### 1.2 输出定义

需要确认：
- 输出是连续往复、周期接触还是分离式冲击
- 频率如何定义
- 行程如何测量
- 负载如何定义
- 接触力如何测量
- 输出一致性如何评价
- 工作周期如何定义
- 哪些参数需要用户调节
- 哪些参数需要闭环控制
- 需要怎样的异常输出保护

### 1.3 驱动系统

需要研究：
- 旋转电机与直线执行器的可行性
- 电机转速和转矩工作点
- 峰值和连续工作能力
- 电机惯量与传动惯量匹配
- 驱动器电流与功率需求
- 启停动态响应
- 负载变化对输出的影响
- 热管理与保护

### 1.4 机械机构

需要研究：
- 运动转换方案（偏心/曲柄/凸轮/直驱）
- 运动自由度
- 输出杆导向
- 偏心轴或曲柄载荷
- 轴承与导向寿命
- 接触载荷路径
- 结构刚度与模态
- 运动部件平衡
- 连接件疲劳
- 维修与拆装

### 1.5 制造与验证

需要研究：
- 关键零件制造方式
- 材料及热处理
- 加工公差
- 装配基准
- 检验与测量能力
- 台架与夹具设计
- 传感器量程与带宽
- 样机制造计划
- 设计验证与耐久测试
- 维护和返修策略

## 2. 后续计算工作分解（ENG-001 ~ ENG-012）

| 工作编号 | 工作内容 | 主要输入 | 预期输出 | 进入条件 |
|---|---|---|---|---|
| ENG-001 | 需求参数化 | 已批准需求 | 参数表与单位定义 | 阶段 1 输入完成 |
| ENG-002 | 运动链建模 | 候选机构与几何关系 | 位移、速度、加速度模型 | 机构候选明确 |
| ENG-003 | 电机工作点分析 | 运动模型与负载需求 | 转速、转矩和功率需求 | 输出要求已定义 |
| ENG-004 | 惯性载荷分析 | 运动部件质量与加速度 | 惯性力与反力 | 质量模型可用 |
| ENG-005 | 接触动力学研究 | 接触模型与载荷条件 | 接触响应模型 | 接触模式明确 |
| ENG-006 | 轴与连接件分析 | 载荷、材料与几何 | 强度与疲劳输入 | 载荷路径明确 |
| ENG-007 | 导向与轴承选型 | 载荷、速度、寿命目标 | 候选器件与寿命分析 | 工况明确 |
| ENG-008 | 热分析 | 损耗、热边界与工作周期 | 温升模型 | 器件和工况数据可用 |
| ENG-009 | 模态与振动分析 | 质量、刚度、边界条件 | 模态与振动风险 | 结构模型可用 |
| ENG-010 | 公差分析 | 关键尺寸与装配基准 | 尺寸链与公差建议 | 架构基本稳定 |
| ENG-011 | 风险控制分析 | 风险登记表 | 控制要求和验证方法 | 风险分析输入完整 |
| ENG-012 | 验证夹具设计 | 测量量和工况 | 台架方案与传感器需求 | 测试目标已批准 |

### 工作依赖关系（概念）

```
ENG-001（需求参数化）
    │
    ├── ENG-002（运动链建模）
    │       │
    │       ├── ENG-003（电机工作点）
    │       └── ENG-004（惯性载荷）
    │               │
    │               └── ENG-005（接触动力学）
    │
    ├── ENG-006（轴与连接件）
    ├── ENG-007（导向与轴承）
    ├── ENG-008（热分析）
    ├── ENG-009（模态与振动）
    ├── ENG-010（公差分析）
    ├── ENG-011（风险控制）
    └── ENG-012（验证夹具）
```

实际顺序应根据输入可得性和关键路径动态调整。ENG-005 接触动力学研究尤为关键，因为它不仅影响机械设计，还影响后续所有验证计划的设计。

## 3. 计算模型审核规则

每份计算报告必须至少包含以下 15 项：

1. **计算目的** — 为什么做这个计算？
2. **计算版本** — 标识便于追溯
3. **输入参数及来源** — 每个参数有编号、来源文档和当前状态
4. **参数单位** — 所有物理量必须显式标注单位
5. **模型假设** — 理想化处理和简化
6. **边界条件** — 约束、载荷、初始条件
7. **控制方程** — 使用的数学关系
8. **计算过程** — 步骤和方法
9. **结果及有效数字** — 避免过度精度
10. **敏感性分析** — 关键输入变化时结果的变化范围
11. **不确定性说明** — 模型限制、参数误差、未考虑因素
12. **模型局限性** — 明确哪些场景下不适用
13. **与设计要求的比较** — 是否满足、差距在哪里
14. **需要通过仿真或实体试验确认的项目** — 不能全靠计算
15. **审核与批准记录** — 谁审、谁批、日期

如果输入参数尚未确定，应使用**符号、参数区间或情景分析**，不得用没有依据的数字填满计算表。

## 4. 开放问题的工程影响总结

| 未知类别 | 若未解决的后果 | 优先级 |
|---|---|---|
| 产品定义 | 机械架构可能朝错误方向发展 | 最高 |
| 输出定义 | 运动学模型无法建立有效约束 | 最高 |
| 驱动系统 | 电机选型无法论证，驱动转矩未知 | 高 |
| 机械机构 | 方案比较只能停留在定性层面 | 高 |
| 制造验证 | 无法制定可信的样机计划 | 中 |

**必须先解决产品定义和输出定义中的核心问题，再推进具体计算。否则，计算可能建立在错误的输入之上，造成返工。**
